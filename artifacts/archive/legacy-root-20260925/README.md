# Legacy Root Artifacts - 2026-09-25

This directory contains the first physically archived root workbooks from the
repository cleanup pass. The files were moved without changing their bytes.
Their original names and SHA-256 values are recorded in relocation-record.json.

These workbooks were superseded historical candidates. At the time of movement
they had no current runtime pointer, code consumer, test consumer, or sibling
manifest path binding. The canonical workbook and receipt-bound runtime
evidence were not moved.

Historical documents that still show the old root filenames are records of the
publishing moment, not current entry points. Current user-facing artifacts are
listed in artifacts/current/README.md.
