# C/D2/F1：从经济事实到条件估值

1. 先按经济结构选画像和模型，解释盈利、再投资和资本配置机制。一般企业模型不替代金融或未覆盖行业模型；画像可用不等于模型可算或可采用。研究企业质量和现金能力时不把当前股价反推成事实。
2. 重放可核事实，再列 Bear/Base/Bull 各自的可反证假设、参数约束、证据来源和失效观察。逐年计算经营结果、再投资、营运资金、融资和可分配现金。已报累计期间加有依据的剩余期间路径，不简单年化；与旧全年计划冲突时写明差额和隐含剩余期间，并区分压力试算与新预测。
3. 合并口径的利润、现金与母公司可支配现金分开。核对上划、少数权益、受限资金和义务，逐项区分本金、利息、净新融资及现金时点，再核对分配资格和实际支付。正现金不证明可分配利润或获批。见 [现金与终值反例](references/cash-terminal.md)。
4. Python 计算金额，Agent 提供来源解释和假设草案。说明适用模型、估值日、股数口径、逐情景结果、驱动敏感性和反证。比较有限优势期与续存/终值，避免同一分红既在模型现金流中计入，又加回估值。终值关键证据不足就封存缺口或拒绝，不为凑齐三情景填零或借用别的情景。
5. 模型可计算、已选主区间、人工采纳、当前可比价格是不同状态。条件结果只能交给既有消费者，当前价格另走 F2，不替代 G3，不产订单。
