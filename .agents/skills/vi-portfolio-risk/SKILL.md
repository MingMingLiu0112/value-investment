# S1–S4：组合、手工记账与连续性

- 区分公开条件计划、隔离模拟、经用户确认的私人账簿。缺真实 IPS 或持仓时个人数量和仓位留空；只做非个性化研究或显式标记的隔离测试。公共 GitHub 不含私人输入、账簿、个人凭证、账户标识或原始运行文件。
- 对价值、热点分别记录策略预算和原始 Entry Thesis，再在共享层检查总现金、未结义务、集中度和行业/两策略重复持仓，避免两套策略各自花同一笔钱。计入手续费、最小交易单位、T+1 和实际可卖数量；区分仅预览与用户确认的手工成交。
- 手工成交以确认凭证对账，结果可重读、避免重复计入。变更/纠错保留历史；不支持的操作要明确拒绝，不做后台修账。分红区分公告权益、预期日期及实际到账，按账簿证据入账并防重复。
- 复核从原 Entry Thesis 到新事件和风险状态，区分理由仍成立、需要补证、已失效。缺原入场证据不反推编造；有显式退出或复核条件但不发订单。模拟对账通过不代表真实行情、真实组合或用户采纳均通过。

交付：账户类型、现金/风险来源、可核对的操作前后、未知项与触发下一次复核的条件。生产调度、真实持仓读写和真实买卖不由 Skill 授权；恒为 `action=no_order`。
