# F2：当前价格可比与条件决策

先冻结确切候选、descriptor、估值日、比较日、合格报价与手工批准的适用范围。按五维分别给结果与阻断原因：

| 维度 | 需要核对 |
| --- | --- |
| 报价 | 交易所、证券、币种、已完成交易日和原始收盘；观察价/已核验历史价不是当然的当前资格。 |
| 股本 | 起止股本与全期间行动、适用类别；股本金额不是股数，回购库存不是注销；没有公告不能直接证明未变化。 |
| 期间分配 | 预案、批准、实施公告、登记、除息、支付分别标注；用模型期间、分母和渠道核对内含与否，避免重复回加。 |
| 重大事件 | 完整原始公告窗口和精确候选材料性复核；不能拿盘中零条当全日覆盖，不能拿旧候选复核代签。 |
| 财务更新 | 新财报及经济影响；若改了模型输入，先得到可独立重放的新研究版本，再重新对齐。 |

五维通过后仍须核对模型采用和显式价格政策、阈值理由及有效期；不能以旧历史政策自动续期、浏览器补公式或强加统一安全边际。保留 `UNASSESSABLE` 与经核查后 `NO_TRADE` 的区别，缺项不给当前条件价。历史未批准参考线 ≠ 当前可比值 ≠ 买入许可。

验证至少包含同候选五项齐备的正向走查和错配/漏覆盖的拒绝；合成正例只证合同，真实业务资格另验。输出候选绑定、五维、衍生结论和下一项待补证据，`action=no_order`。
