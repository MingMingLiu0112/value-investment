# E1/E2：首编和有证据的后继

- **没有可消费旧候选走 E2。** 绑定证券、财务主体、C 画像、D2 封存经营及现金研究、来源清单和模型输入。用现有共享编译器；保留局部事实或模型不适用的拒绝，不从历史候选借批准、不写股票代码特例。
- **已有候选走 E1。** 冻结前驱与确切输入，识别真实新财报/公告、规则变更或有依据的假设修订。逐项写“原事实／假设 → 新证据 → 改变、保留或拒绝 → 逐年经营、分配和估值影响 → 重开条件”。有能力改变决策的是证据，不是价格变动、打印精度、延长有效期或改元数据。历史假设重放不得称作新公告。
- **按版本冷重放。** 核对证券、候选及 descriptor、来源字节、规则、会计口径和上海交易时点。来源变化/时间倒退/同名跨版本/损坏均明确拒绝。锁定的原件、批准回执和旧结果不覆盖、不改日期、不重签。先用同一共享内核独立复算前驱与后继，再用既有注册、API 和公司页核对消费的确切版本。
- **交付不同层级的结果。** 事实已接入、经济假设已采用、F1 有条件估值、F2 当前可比及人工批准分别记录。若没有有效的经济变化，可以保留已有研究并解释为何无需新候选；确实缺材料性的不得标“无影响”。
