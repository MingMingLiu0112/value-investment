# A/B：公开事实和候选证据

1. 确定证券、报告期、财务主体、知识截止时点和交易日历。分开保存事件或报告的有效日、原始发布时间和系统观察/可用时间；后来取得的旧文件不是当时可用的事实。来源优先交易所、巨潮、发行人原件；聚合源可索引或交叉检查，不能静默替代原件。
2. 固定原始字节、来源 URL、哈希、页/表/行、会计主体、币种和单位，再提取事实。检查报告是否完整、期间是否相邻、比较栏是否错读、OCR 数字/符号是否正确、财务数值是否勾稽。原件空白、抓取失败、范围不清都不转写成零。部分覆盖可以显示，但不得当完整事实。
3. 分开报告公司数：官方名单、可用市场观察、财务可筛、各通道入列、正式准入。按交易所/板块保留覆盖与失败理由；保留四通道（质量复利、股东现金回报、低估、周期）的各自理由和拒绝，合并证券身份时保留多通道归属，不以单一 PE/PB 或数据缺失统一排名。
4. 只读任务检查既有来源和回执，不触发采集；明确允许有界刷新时，只补能改变筛选、模型适用、材料性或估值的缺口。把验证、运行、恢复和冷重放当成不同操作，并交付下一次重开触发条件。

验收：完整原件可重放到同一事实和筛选理由；少一个交易所、错列、未来已知、源字节改变，其受影响决策明确降级，不拖停其他可独立模块。输出覆盖表、证据角色、入列/拒绝理由和生效时点，保持 `action=no_order`。
