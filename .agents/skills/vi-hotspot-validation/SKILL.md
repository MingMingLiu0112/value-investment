# 热点波段：独立验证，不沿用价值准入

1. 热度与多周期价格结构分开。固定证券/板块观察、完成日线/60 分钟/15 分钟、各周期的可用时点、关键位、入场确认、保护位和失效条件。只有公告/热点或未完成 K 线，不能形成有效入场。复用身份和组合约束，不把价值通过当波段通过，也不把反向关系当硬门槛。
2. 固定复现数据、窗口、阈值和成本后再看验证结果。验证当时可获得的名单、证券行动原件、分红与复权口径，显式拒绝未来信息、漏覆盖和回看筛选。研究 K 线与成交价格单列；保守处理 OHLC 同一根 K 同触入场/止损、涨跌停、停牌、跳空、T+1、费用和滑点，不假定一定能成交。
3. 分开报告合同测试、回放、独立样本外/滚动检验、适用的授权自然时间 Shadow 和最终复核。保留失败/未成交样本，与透明基准对照，报告覆盖、可成交性、收益分布、回撤和成本敏感性；不能反复调参到通过，也不能用回放替代真实交易日。区分无信号与数据不可评。
4. 不够时只给观察、拒绝原因或待证事项。明确下一项能改变结论的证据；不单凭 CI、签名、个股正例或其他策略进度升级。最终操作交用户，`action=no_order`。
