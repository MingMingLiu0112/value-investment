已逐项读取 `Valuation output` 工作表：

| 单元格 | 原公式 | 对项目的约束 |
| --- | --- | --- |
| C9 | `=C7-C8` | FCFF为税后经营利润减再投资，不等于经营现金流直接作为永久分红 |
| M8 | `=IF(M2>0,(M2/M40)*M7,0)` | 原模型正增长终值阶段以增长率/资本回报率计算再投资比例 |
| B18 | `=B16/(B17-M2)` | 终值对资本成本与增长率差高度敏感，项目须校验资本成本大于增长率 |
| B19 | `=B18*L13` | 终值需要折现，不能直接加到现值 |
| B29 | `=B24-B25-B26+B27+B28` | 经营资产价值扣债务和少数股东权益，加现金及非经营资产 |
| B31 | `=B29-B30` | 普通股权益还需处理期权价值 |
| B33 | `=B31/B32` | 每股价值必须匹配权益范围和股份数量 |

结论：不能因已获取净利润、净资产就宣称FCFF输入齐全。再投资、完整债务、
少数股东权益、非经营资产、股权稀释及折现假设是后续数据契约的一部分。
原工作簿的成熟期风险溢价等默认参数不是A股参数证据，不直接照搬。

## 现有实现的审计结论

将可用的EPS_TTM乘PE、BVPS乘PB取均值。它是显式假设的参考价，
不是从现金流、增长及风险推导出的已验证合理价。
2026-09-08复核v2代码：只有EPS_TTM和BVPS均为正且报告期一致时才生成
组合参考价；单项缺失不再退化生成组合价格，分项参考值仍可保留。
当前资料没有为这些固定倍数或等权平均提供
实证验证，也没有证明30%折价在A股最优。

## 后续模型契约

1. 非金融企业先研究FCFF，并用可比倍数作交叉检查；稳定杠杆企业可研究
   FCFE。必须明确现金流属于企业还是股东，匹配WACC或权益成本。
2. 银行另研究DDM/超额收益框架，同时保留资本约束和风险指标；不套用
   普通企业债务扣减逻辑。此处不代表银行模型已经实现或验证。
3. 输入按历史实际可用日归档；折现率、增长、再投资、股数及企业价值到
   股权价值的调整都应留存来源、假设版本和一致的币种/合并范围。
4. 主模型和交叉检查分开展示，模型分歧作为风险提示，不自动求平均。
5. 先输出保守/基准/乐观情景及敏感性；参数尚无依据时保持研究状态，
   不生成具有交易批准含义的单点价格。
6. 数据验证、公式验证、参数论证和样本外收益验证分别记录，不能因为
   数据来自年报便认定未来现金流预测或交易时点正确。

下一步应读取原作者具体模型及金融教材/研究的第二来源，冻结一个可复现
基准模型，再接入历史样例。当前不替换生产规则或放宽已有数据门禁。

## 2026-09-09：独立年度FCFF研究计算器

新增 `scenario_valuation.py`，版本 `annual-fcff-explicit-bridge-research-v1`。
实际复用上述原始工作簿公式依据，不照搬其中折现率或增长率。新计算器未接入
生产估值或Excel，不取代旧参考模型。

输入为显式年度EBIT、现金税率、折旧、资本开支、营运资本增加和WACC；负EBIT
不自动生成税款退回，亏损抵扣等复杂税务须另建模型。逐年累计折现因子，终值使用
下一年NOPAT乘(1-g/ROIC)并除以(WACC-g)，再折现至起点。只支持非负稳定增长、
可持续非负终值现金流；收缩及有限寿命企业须单独模型，不能强套该终值。

股权桥接区分非经营资产、金融子公司股权、债务、少数股东、稀释及其他优先索偿。
每项明确声明经济范围，和经营现金流或其他桥接重复的范围ID会被拒绝。该检查只
验证调用者声明不重叠，不能自动发现被改名掩盖的重复资产；真实范围仍需原件审阅。
输入金额为同一币种完整金额，股数为真实股数，不是股本金额或亿元单位。

所有年度原始参数、终值参数、桥接项目及引用保留到结果。引用字符串本身不是
来源真实性或历史可用性的证明，结果固定为research_arithmetic_only，且
evidence_authenticated/assumptions_validated/strategy_approved均为false。

当前时间约定是起点至首个年末一整年，随后年度现金流。年中估值须补齐首期长度、
现金流日期及当时已知输入契约后才可接入；不能直接将2024年报当2026年当前估值。
缺少来源的折现率、增长和范围调整没有默认值，也不以财务公司账面权益代替公允价值。

已用独立闭式永续公式及人工可核对的两期折现例验证数学，涵盖桥接正负号、
重复范围、负利润税务、负股权、股数、缺引用和终值边界。与旧估值测试共46项通过。
这些为合成数值验证，不是茅台三情景价格，更不是收益回测。

公司接线下一步：将茅台工业/金融抵销和索偿整理为有来源的范围项目，完成年度
情景参数及独立专业依据，明确估值基准时点，再调用计算器生成真实研究估值包。
