## 2. 目标拆成三个可完成的阶段

- R0研究：让用户看懂公司为什么入选、赚什么钱、财务是否可信、价值区间及关键风险。
- R1模拟：冻结规则，以独立虚拟账户运行，能复现每笔候选、拒单、成交、费用与净值。
- R2人工小额实盘辅助：限定已验收的股票、模型和账户范围，输出可解释的人工执行方案；用户自行确认下单。

第一业务交付只要求一家公司完整闭环，再扩展固定三案例和6至10家深度研究队列。既有全部公司继续基础跟踪，不要求全池全部字段填满后才交付。数据充分的公司也可以结论为“不值得买”。

每阶段独立验收。研究报告合格不代表策略合格；真实回测收益为正不代表风险可接受；30个交易日观察只验证运行，不证明长期超额收益。

## 3. 系统及数据路径

流程：正式披露/行情原件 -> 不可静默改写的原件归档 -> 标准化事实 -> 字段验证与历史可用性 -> 公司研究 -> 情景估值 -> 决策规则 -> 账户与成交约束 -> 原Excel。任何结论都保存输入事实ID、版本和run_id。

服务器负责轻量增量采集、PostgreSQL及既有定时任务；D盘负责开发、重型历史研究、预览和备份。WPS只保留唯一正式Excel。数据库物理文件不能通过WPS同步，多设备通过受控远程数据库连接或项目导出访问，不依赖本地Docker。

## 4. 股票筛选和跟踪频率

月度执行全市场初筛，财报季及重大事件可增量重评；日常重点更新候选和持仓。持仓公司即使不再符合初筛，也必须继续监测。

保留原PE<=25、PB<=3、市值>=50亿元为旧基线；新增同行质量和可持续现金回报研究通道。三通道取并集，保留各自入选原因，不把三个不同量纲的排序混成买入分数。

深度队列首先按资料覆盖、商业可解释性、模型适用性选择，不按已知收益选股。固定历史案例为600519、000333、601088。银行、保险和券商仍保留观察，但专用模型没有验收时不得套非金融模型给买点。

每日检查收盘行情、重大公告、持仓风险和已有触发价；新财报或重大经营变化才触发完整财务/估值重算。仅股价变动不应自动改变公司内在价值假设。

## 5. 公司好坏：财务与商业判断分开

财务至少研究5年收入、归母及扣非利润、合并利润、ROE/ROIC、经营现金流、资本开支、营运资本、完整债务与每股变化。不同利润口径不混用，TTM严格使用可比的全年+累计-上年同期。

财务新评分候选为盈利30、现金25、偿债25、成长及资本配置20，总分70仅作实验入围线。执行前必须把每个子项的原始量、分档、行业适用性、缺失处理及理论依据写成配置；没有这张表不得直接生产一个AI总分。旧35/25/20/20版本继续作为独立对照。

商业研究必须逐项回答：客户为什么付钱、收入由销量还是提价驱动、竞争对手为什么难以替代、维持增长需要多少资本、管理层如何分配现金、什么事实会推翻投资逻辑。每项提供正证、反证、同行比较、引用和失效触发条件。

风险硬门禁独立于得分：重要债务范围未知、重大持续经营疑虑、无法解释的财报冲突等不能靠其他高分抵消。资料缺失标未知，不判公司差，也不默认中等分。

## 6. 价值与价格判断

非金融企业优先研究FCFF：税后经营利润+折旧摊销-资本开支-营运资本增加。折现得到经营资产价值后，明确加回非经营资产并扣除匹配债务、优先索偿、少数股东及适用稀释，最后除以相同权益范围的股数。

家电研究竞争、渠道库存及海外现金流；煤炭研究正常化煤价、资源寿命、低谷资本开支及恢复义务；公用事业研究电价、水文、债务及建设期。金融企业采用股权现金流/超额收益等专用模型。不得把FCFF用权益成本折现，或把FCFE用WACC折现。

保守、基准、乐观情景分别建完整收入、利润率、再投资和折现假设。输出V_low、V_base、V_high，不把情景范围称概率置信区间。相对PE/PB仅交叉检查，不机械与DCF平均；分歧必须解释。

安全边际统一为 `1 - P / V_base`，同时显示相对V_low的折价和主要下行情景。措辞规则：

- P低于V_base，只能先说明“低于基准情景价值”；是否足够便宜另看已冻结买入阈值。
- P接近或高于V_base，分别说明与基准的关系，不能由折价不足15%直接断言高估。
- P超过V_high，说明“超过本模型乐观情景”，仍注明假设范围。
- 估值输入不齐，显示具体缺口；不从当前价格反推一个合理价来消除空白。

## 7. 买卖决策的可执行契约

每次决策固定顺序：重大风险 -> 证据/模型资格 -> 企业条件 -> 价格 -> 账户预算 -> 可成交条件。风险提示独立输出；行情失效会阻断精确订单，却不能隐藏已经披露的重大持仓风险。

买入实验沿用基准价值30%折价，并报告20%/40%敏感性。它是待验证假设，不是价值投资普适定律。实际买入候选须所有门禁通过、已有账户快照，并根据次日可接受限价核算风险；不能把前日收盘触发等同次日任何价格都可买。

每个策略配置必须在回测前补齐以下参数，否则不能启动收益实验：首次建仓比例、加仓条件及次数、单股和行业上限、现金储备、减仓触发与比例、基本面退出事件、重新入场条件、限价有效期、未成交处理及同日冲突优先级。沿用v2已有实验初值并说明依据，不在运行时临时决定。

持仓输出区分：继续持有、停止加仓、估值减仓研究、组合超限减仓研究、基本面失效退出研究。不同退出原因保留独立证据。单纯下跌不自动加仓，单纯数据缺失不自动清仓。

配置必须采用统一组合预算，不允许每只股票都独立建议10%而总计超仓。模拟账户可先用100万元，实际账户资金和持仓未知时不输出真实下单股数。数量按对应板块交易单位取整，现金包含手续费，考虑T+1、停牌、涨跌停和流动性。

## 8. 回测先完成一条真实链

先对固定三案例形成必要输入矩阵，优先资料最充分者。复用已归档年报和历史价格，补齐真正依赖的股数、财报可用时点、公司行动和费用。不要无限扩展不影响本次模型的附注解析。

沿用2015-2025、开发2015-2019、验证2020-2022、测试2023-2025的协议；后段已被接触，不宣传盲测。若只能重建年报策略，另建明确的低频实验，不能冒充季度TTM策略完成。

决策仅使用当时已公开的信息。更正后的财报和今天的商业评价不能回填过去。收盘后信号最早下一可交易会话尝试成交；未复权价格和独立公司行动账本避免重复复权与重复分红。

保留同股买入持有、旧规则、新估值、新质量、新风险退出的逐层比较。按相同起始资金、成本、日期报告收益、回撤、现金占用、平均股票敞口、换手、分红贡献、费用及所有失败版本。没有足够交易或历史证据时判inconclusive，不人为放宽门槛制造成交。

先注册唯一主用途：净收益改善，或在明确收益代价内降低风险。量化验收线由专业依据、实验目的和风险预算确定，在查看结果前固定。三只成功案例不能证明全市场有效，应增加事前选定的困难/失败案例作稳健性研究；无法取得历史退市范围时禁止推广结论。

## 9. Excel交付

优先复用 `21_决策验证`，把用户入口组织为：今日变化、持仓风险、可研究候选、待补证事项。字段至少包括公司、状态、数据截至日期、商业摘要、价值区间、现价、触发价、买卖理由、未通过条件、策略范围、实际/模拟标识及证据链接。

研究、年度财务、估值、指标证据和账户页互相可追踪，不再重复复制同一批明细。一个公司只维护一个稳定身份和一套当前研究记录，历史版本追加保留。

原表只通过既有预览、验证、备份、原位替换流程发布。保护人工研究、实际持仓、交易和月度历史。验证WPS可见数值或公式缓存，不能仅凭openpyxl保存成功宣布显示正确。

## 11. 运维和风险边界

复用既有调度及共享锁，不新增重复服务。保护PTA、Hermes及PostgreSQL；保持既有CPU/内存限制和2GiB储备，重任务放D盘。检查服务实际输出，不把timer存在或退出0视为全链成功。

每日数据库、原件、配置清单和工作簿备份独立于行情成功；客户端加密后放已授权异地位置，密钥另存。实际恢复必须指向隔离库，比较行数、规范化表Hash、原件及Excel结果，报告实测RTO/RPO，不以备份文件存在代替恢复验收。

用户只需提供公开信息无法推知的本金、真实持仓、费用和风险预算；补财报、判断口径、调查冲突由Agent完成。无法解决的事实保留缺口，不要求用户替代专业核验，也不自动视作通过。

每轮选一个关键路径交付，完成实现和必要真实验证后记录进度。接口单轮有界重试，失败后用明确替代路径；非关键字段两条路径仍无结果则保留未知并推进其他工作。禁止只增加文档或测试数而不推进业务闭环。

目标指令见 `value-investment-goal-prompt-v3.md`。本轮只是交付方案；不据此创建新的自动化、修改策略或替用户交易。长期完成以阶段证据衡量，无法满足R2时如实保留不准入结论，不能降低标准来宣称实盘就绪。
