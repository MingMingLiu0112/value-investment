## 从事实进入三情景的剩余工作

1. 经营预测：用2025全年、2025H1、2026H1的同口径产品收入和成本建立TTM与季节性对照。茅台酒和系列酒分别建增长与成本，渠道只用于解释结构，不再叠加收入。补同行/行业的独立反证后登记悲观、基准、乐观假设；不为达到目标价倒推参数。
2. 工业现金流：核定金融与共享费用分配，税率区分会计和现金；折旧包含生产成本中的折旧，不只取管理费用附注。基酒存货、票据应收、预收、经销商保证金和经营应付纳入完整营运资本。财务公司资金释放不外推为工业现金流。
3. 再投资：在建预算不是尚待支付额；维护与扩张无法精确披露时以明确假设区间建模，并用历史实际资本开支、折旧与产能约束检验，不以缺失等于零。
4. 权益桥接：金融股权只计上市公司所持51%；对工业现金流所包含的销售公司少数股东收益估值，不能机械扣账面权益。现金要扣营运所需、受限和外部索偿，并核对内部存款抵销；租赁与FCFF处理一致。报告期后股本事件仍需检查。
5. 折现：国债到期率不是即期折现曲线；百分数转小数也未证明年有效复利。明确人民币风险基准、经营地区风险、可比Beta和杠杆，登记折现率/终值增长/再投资敏感性。2026参数不得回填2015历史。
6. 输出：沿现有scenario_valuation计算器生成三组逐年现金流、终值占比、权益调整和每股区间；独立复算后接入既有公司研究、估值、决策验证页，不新增重复Tab。完整输入未就绪时不伪造数值区间。
