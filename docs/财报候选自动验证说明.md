# 财报候选自动验证

`14_财报候选` 是 Agent 从交易所/CNINFO 法定披露原件自动定位出的候选数据，不能直接用于估值或交易信号。

无需人工复核。系统会对每个候选自动执行以下验证链：

1. 归档原始公告 PDF，并记录公告 URL、发布时间、SHA-256、页码和原文片段。
2. 从独立结构化来源取得同一证券、同一报告期、同一单位的指标。
3. 对 ROE、每股净资产和每股收益按字段容差交叉比对；不一致、缺失或报告期不匹配时保持 `candidate_pending_automated_verification`。
4. 仅在比对通过后写入已验证数据点，状态标记为 `automatically_verified`，且保留两条来源的 ID。
5. 估值、建仓候选和目标仓位还必须通过行情时效、估值参数、行业专用规则和数据冲突门禁；任一门禁未通过都只显示为“等待数据”。

因此，`13_全市场初筛` 是研究队列，`14_财报候选` 是自动补证队列，`01_观察名单` 只保留证据链和估值门禁均通过的公司。系统不自动交易。
