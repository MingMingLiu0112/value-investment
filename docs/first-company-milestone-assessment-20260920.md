## 当前判断

首家公司已经完成“研究、证据、实验机制和 Excel 可见性”的可审计最小闭环，但没有完成“正式估值、有效策略和实盘准入”闭环。当前不宜扩展股票池或模拟组合，因为这会复制尚未通过样本外检查的模型与执行假设。

历史范围和相对 PE 两条实验都未提供样本外支持。继续围绕它们调整阈值或选择收益较高端点属于数据窥探，应停止。当前最有价值的工作顺序是：

1. 对每个新有效会话先生成同日、事前冻结的当前研究观察和日常纸面零单或拟单记录；旧模型不回填旧报价。
2. 为历史价值模型补齐点时资本成本与权益桥接，或在两条独立一手路径均失败后正式缩小历史结论范围，不无期限重复抓取同一接口。
3. 只有基准模型在预注册验证和封存阶段产生可解释、可执行的记录，才比较税后收益、回撤、现金占用和同口径基准；结果不佳则保留失败结论。
4. R1 后才复制至美的、神华和组合；R2 前继续只给出研究与风险状态，不给实盘指令。
