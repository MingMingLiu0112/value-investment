持续完善一个以一手披露为依据、以原WPS Excel为日常界面的人工投资决策辅助系统：识别企业经济价值及市场预期差，完成公司筛选、财务和商业研究、情景估值、买卖与加减仓条件、仓位管理和复盘。投资不只分为捡烟蒂与成长股；采用共同风险底线、投资路径和行业口径相结合的研究框架。争取长期税费后正收益并控制永久损失，但不把“保证稳定盈利”作为可交付承诺，不自动下单。

## 2. 用户必须最终能做的事

| 能力 | 应当得到的结果 |
| --- | --- |
| 选公司 | 多通道初筛理由、候选投资路径、行业适配及研究进度；回答靠什么获得回报、为什么可能被错价。当前候选、固定研究案例、实际/模拟持仓分别标识；低PE/PB不是所有路径的共同门槛。 |
| 跟踪公司 | 最近有效交易日、财报期、财务五问、商业模式和管理层资本配置；重要假设的支持与最强反证、变化及下一事件。过期、缺失、未披露、来源冲突分别解释。 |
| 判断价格 | 按行业和投资论点选择模型、三情景及敏感性；独立估值后检查市场隐含预期。研究条件值、指定模拟适用价值和实盘适用范围分开，不用固定PE/PB平均或目标价投票代替论证。 |
| 获得行动指导 | 观察、买入、加仓、持有、暂停新增、减仓、退出及再入场条件；显示拟变动数量、资金、仓位、理由和失效条件。尚未满足时给出具体原因。 |
| 管账户与复盘 | 独立模拟现金、股份、费用、分红、净值和订单事件；人工账户与真实交易另存。相同输入重跑不重复成交或记账。 |

### 2.1 共同底座与投资路径

每家公司先记录投资论点、主要回报来源、可能的错价原因、最强反证及价值实现方式，再选择主路径和可重叠的辅助标签。行业类别是另一独立维度；标签不等于推荐、评分通过或模型准入。尚未判断时写“未分类”，不凭行业、低估值或股息率自动贴标签。

| 研究路径 | 核心价值依据 | 开发边界 |
| --- | --- | --- |
| 资产折价 / 烟蒂 | 可变现资产扣全额索偿、处置成本、现金消耗及实现时间；区分账面折价和可回收价值 | 后续独立证据与回收情景，不用低PB替代清算分析 |
| 成熟优质复利 | 持续盈利、竞争优势期限、边际资本回报及每股增长 | 首例茅台的候选主路径；仍须完成假设与模拟适用性验收 |
| 成长价值 | 需求、份额、单位经济性、增量资本回报与融资稀释 | 复制美的后按具体业务验证；不能仅凭收入增速命名成长股 |
| 现金回报 | 扣必要投入和债务后的可持续分配及总回报 | 与成熟企业路径交叉；高股息、国有身份均不等于安全 |
| 周期正常化 | 中周期盈利、供需与成本曲线、资源寿命和低谷生存 | 固定神华案例；不能拿周期顶点低PE当便宜 |
| 困境反转 | 经营及融资修复、现金跑道、失败损失和索偿顺序 | 暂不支持新增投资判断；先建立专项能力 |
| 特殊情形 | 重组、分拆或处置的合同条件、完成时间及失败结果 | 暂不支持事件套利建议；须专项事实及规则审查 |

路径非穷尽、非互斥，不能将同一业务的资产价值和持续经营价值重复相加。前期只完成当前案例实际需要的组件，不并行开发七套引擎。

所有适用公司须回答财务五问：利润质量如何、盈利能否持续、现金是否可用并归属普通股、低谷能否生存、留存资本是否创造每股价值。管理层评价看承诺兑现、关联交易、融资摊薄、并购/回购价格和中小股东利益，而非个人形象。财报勾稽或Hash一致只证明对应证据链和处理一致性，不证明发行人绝无造假；异常触发核查，不自动定性舞弊。

### 2.2 一家公司应交付的研究结论

交付一张可更新研究卡：`行业与路径 -> 投资论点/回报来源/错价假说 -> 五项财务诊断及治理 -> 业务驱动与反证 -> 适用模型和情景 -> 市场隐含预期 -> 持有/买入/加减仓/退出条件 -> 下一验证事件`。每项区分事实、推断、预测及未知，绑定日期和证据；市场错价未论证时明确“尚未证明”，不把买入理由写成确定事实。

研究与自动执行分开：反向估值先选少数关键变量，解释当前价格要求怎样的增长、利润率、资本回报或优势期限；不能唯一识别时给条件组合，尚未实现时显示缺口，不反调独立估值来迎合市价。它是首例模型有限审查的解释性输出，不是第二套主策略，也不要求先建全行业预测系统。

买卖依据按路径和当前内在价值变化制定；共同的证据、重大风险、账户和执行门禁保留。30%安全边际、至少5年及到基准价减仓/乐观价退出只属于现有长期持有候选实验，不能推广为烟蒂、周期或事件策略的通用定律。本轮不修改已登记的实际参数，不回写历史实验。

R0研究可用、R1指定范围的模拟跟踪可用、R2人工小额实盘准入分别验收。合格的模拟不需要先证明盈利；实际交易指导仍须通过模型、历史、运营和账户适用性要求。原表中的模板100万元或0股不是用户已确认的真实资产。

R1之前允许交付“日常模拟可运行，历史验证未完成”，开始保存真实会话下的前瞻记录；这不是新增实盘等级，也不等于首例R1。当前可用模型、真实模拟账本和完整执行机制仍须通过相应检查，不能把现有固定no_order研究摘要改名交付。界面同时显示日常运行、历史验证和实盘适用状态，避免用户把“已运行研究”理解成“已跑通交易”。

### 2.3 市场环境层：辅助风险判断，不替代公司研究

整体决策顺序为：公司事实与投资论点 -> 独立估值及价格条件 -> 账户和执行约束 -> 行动方案。市场环境作为独立、可关闭的旁路输入：未通过增量验证前只展示，不改变合理价、建仓资格、仓位或退出规则；看多不能挽救公司条件不合格，看空也不自动命令清仓。既有重大风险处置不等待此模块。

参考 a-share-monitor 的信用环境、估值与拥挤度分层和无效指标退出机制；不照搬阈值、权重、仓位区间、回测数字或预测能力声明。技术与实证契约见框架第1.1节。最初限市场估值、信用变化、实际换手率和历史波动率四类；区分市场状态观察、待检验预测假说与通过验证的仓位规则。行业涨跌不等于行业估值，市场盈利收益率与国债利差不直接替换公司模型的股权风险溢价。

该层不是P1-P3、首例日常模拟或R1的新前置条件。先完成茅台最小闭环，再以影子观察方式复用采集、审计和现有Excel页面；没有实现时明确“未接入，不参与决策”，不填中性分数。正式影响仓位前，另做有无该模块的同条件对照及样本外验证，失败则保持观察或停用，不反复优化到历史表现满意为止。

## 4. Excel MVP 阶段 B 后的三个技术工作包

第1.1节研究卡验收后，按P1当前适用模型 -> P2当前决策/执行/持久化账户 -> P3真实行情运行和原表发布 -> P2历史连续窗口与R1推进。这些技术条件不阻断有日期和证据的人工研究交付。已有模拟组件继续复用，修复只围绕当前交付的必要依赖，不以审计旧历史细项替代公司分析；不能只翻转批准标志。

### P1：确定可用于指定模拟的输入与模型

复核当前条件估值的实际依赖，形成一份紧凑的“事实 / 假设 / 缺口影响 / 适用结论”。先复用现有模型，按公司经济口径选择一个主模型与一个必要的交叉检查，不把现金锚、DCF和PE并列扩展为三个主策略。

`build_moutai_consolidated_equity_inputs.py` 已从钉住Hash的官方索引推导日期级可用时间，并从股份表直接读取股数；模型及当前观察使用纠错依赖。复用相关验收，后续新增财报仍按同样方法，禁止把后来披露提前用于历史决策；元数据纠错沿依赖生成新版本，不能只改说明文字。

current_disclosed_basis已完成上述核验并生成新版本。75%分配/25%留存已登记为当前强衰减情景的研究假设，不是公司承诺或主模型准入。当前代码按盈利路径预测，留存不自动获得历史高ROE；已作分红、优势寿命及资本成本敏感性。接手继续有限适用性评审与P1/账户连接，不因有数值就把十年超额回报消退当成中性预期；不重复已完成的原文提取和未受影响回归。详见运行记录。

当前/前瞻基点优先采用已归档2026H1权益、股份及资本变动，事件检索补到本次as_of。分别核对归母净利润与综合收益；分红及回购已进入期末权益时不再扣一次，注销不减少投资者正常持股。使用“最新正式披露股数+之后已公告变动+完整查询窗口”的明确政策，不把不可取得的每日股东名册当绝对前置条件。报表日到估值日之间的盈利/分配与折现时间差必须显式处理，不能宣称已知未披露的当日净资产。

公开但尚未提取的必要事实继续定位原件；未单独披露的内部费用、维护投入等允许采用有依据的区间。能用匹配范围的合并或归母口径解决问题时，不坚持取得内部精确分摊。正常化盈利及有依据的倍数可作交叉检查或有限替代，但必须记录经济理由、范围和版本，不能因为更容易产生买点而换模型。

先登记合理边界和决策判据，再做独立复算与必要敏感性；未知无法定界时不冒充已知。只有具体依赖受阻，不阻断不依赖它的账户、执行或维护工作。一个权威原件中的确定性事实可按字段契约及独立处理检查使用，不机械要求第二家网站披露同一内部数字。

前瞻ROE、分红、留存、增长和衰减是预测假设，验收其历史/同行/政策依据、经济一致性、反证及边界，不要求第三方证明未来值必然正确。资本成本冻结有日期依据的选择政策和基准/压力范围，不把找到唯一“真实折现率”作为任务。模型适用与本日买点分别判定：模型通过后可以仍无买点；正常情景差异交给冻结的价格规则处理，未解决的重大缺口足以推翻拟新增动作时暂停新增。按框架7.3补齐剩余收益与分红交叉检查，不因重命名而批准。

交付：冻结的模型/输入版本、必要事实来源、有限假设及适用范围、是否可驱动指定模拟及原因。结论可以是适用、有限范围适用或不适用；不只交付新增阻断文本。若不适用，明确下一条已有可选路径或哪些功能仍可运行，不擅自换股票完成指标。

### P2：接通同一规则的决策、数量和账户

复用现有simulation_state、virtual_account、估值及订单组件。补齐真实缺失的加仓、减仓、退出、再进入、事件去重和数量预算；先查已有覆盖，不重新编写撮合或记账引擎。

保留已登记30%主实验及20%/40%比较的历史版本。框架第8节的50/30/20分批、8%单股上限等仍是待论证的实验设计，不因写进MD自动生效。首版冻结一份可执行的规则契约；每项条件给出依据、输入依赖、当前实现和数量效果，研究提示与实际模拟拟单分开。

财务/商业判断采用公司适用的必要条件；不要求先实现全行业五年百分位和两个新总分才能验证茅台，但不能把未实现的70/100、14/20门槛写成已通过。已证伪与未知逻辑均不能批准新增；已有持仓的已知风险不被估值缺口吞掉。删减或替代规则须生成实验版本，不伪称完整v2。

规则配置须同时列出触发价公式、必要企业条件、每项假设的依据及适用日期、失效/重置条件、数量算法和当前实现。先做一手可负担性及分批/减仓取整检查；在总上限内适配整数股需独立版本和对照，不为多成交提高限额。策略价格条件通过但账户预算不足是有效的零单结论，不能混为估值失败；100股持仓减去1/3无法按原取整规则执行也须给出预定处理。

用相同状态机覆盖观察、买入、加仓、持有、暂停新增、减仓、退出、再入场、数据异常、资金不足、T+1和不可成交情形。合成数据驱动条件变化后让代码生成拟单，不仅直接塞入两笔预制订单；测试用例与当前真实会话账户分开。完成当前机制后立即接P3。历史回放随后用当时可用资料，按输入完整性事前登记连续窗口并保留全区间缺口；不能为了等待历史收益而延后当前记账和发布。

日线模拟按框架9.3冻结独立执行政策：收盘后决策、下一有效会话开盘加不利滑点、委托限价、历史税费及费用场景、整手/T+1/现金和事前流动性上限。停牌、无量、触板、状态不明及无法处理的公司行动拒绝或延期；普通会话的成交是明确假设下的模拟，不能称真实可成交证据。没有真实订单，无法回溯证明它的排队位置；不能因此把所有普通日永久封死。不同成本/滑点和延迟执行场景单独报告，不靠任选有成交的假设通过。

交付：从条件到拟单/成交再到账户的同一条可复算链；正常零交易也可验收，但必须区分价格不满足、资金/整手限制、无适用模型、全部失败及根本没有生成逻辑。不能为成交而修改阈值、样本或输入范围。

### P3：用一个现有入口完成每日运行和原表发布

优先扩展scripts/run_moutai_simulation_closure.py及已有日常入口，按需调用现有研究、行情、决策、账户和发布模块，不再新增同职责总控脚本。

一次执行应产出：实际输入日期与版本 -> 研究及价值适用范围 -> 当前条件判断 -> 拟单/成交或明确不成交原因 -> 模拟现金/持仓/净值 -> 原表可读结果和运行记录。相同输入、规则、账户状态重跑不重复成交、分红或历史快照；不要求不同运行时间的文件哈希相同。

每日收盘任务先结算此前已存在且本会话可执行的模拟订单和公司行动，再用本次可用信息估值、生成最早下一有效会话执行的拟单，最后保存账本及发布原表。成交判定只读取执行时点已可用信息，不能利用当天收盘后新财报倒改当天开盘拟单。首次日常运行只生成下一会话计划也可合格；没有下一会话数据就保持待执行，不提前伪造成交。具体时序、买卖方向和失效处理沿用框架9.3。

沿用已有本地/服务器任务及共享锁，只修复本次所需的刷新和发布链；不能把旧案例包换时间戳当新行情，不为“一个入口”重写现有所有命令。替换现有仅允许no_order的研究分支时，接真实模拟账本并验证可产生合法拟单和风险动作的路径；不固定返回100万元/0股，也不只放松断言。源失败时保留上一好版本及其日期、明确失败，不让旧批准继续驱动新增风险。

首页、公司总览、估值、决策及仓位摘要消费同一运行ID、模型ID、as_of和账户类型。研究主模型、事实日期、假设、风险或数据时效有实质变化，即使行动仍是观察也属于应发布的业务变化；旧模型保留清晰身份，不能无标记地与新模型混用。首例交付可从原表回答：为什么选这家公司、靠什么赚钱、价值范围来自什么、什么条件买/加/减/退、当前满足哪些、模拟数量受什么约束。

跳过重算/发布的判据必须包含事实/公告、模型与规则版本、行情会话、公司行动、账户状态及输出契约；时钟跨过有效期本身也可能改变结果。行情不变但任一有效依赖改变必须重评，真正相同业务输入才跳过。一次纠错或模型变更需验证整条导出依赖，防止旧缓存让原表看起来退回旧版本。

日常交付：P1当前模型适用、P2当前机制通过，再提供可复用的实际命令、一次真实输入运行、一次幂等重跑、合成分支验收、原表重开结果、账户恢复位置及已知限制。可先记录“日常模拟可运行，历史验证未完成”，开始实际前瞻记录；尚无隔夜订单/事件的真实观测时单独标明。不得把合成成交或后来补跑的会话计为当时已运行。历史期末净值和当前模拟账户分开展示，后续真实会话继续验收跨日运行。

最近交付的最小工作清单到此为止：当前事实验收、有限模型、规则到持久化账本、每日时序、原表一致性。随后补齐历史连续窗口；不在此之前新造评分体系、全市场研究、另一套总控或更多页面。P1-P3及历史条件全部满足后才交付R1，不要求先完成三股、全市场或30个未来交易日。

最小可见成果必须在原表呈现一张600519行动卡：实际行情日期及价格、研究论点和反证、适用价值范围与假设、买入/加减仓/退出的条件和满足情况、下一会话拟单或零单原因、模拟现金/股份/费用及证据。市场环境标注未接入或仅观察，不制造新阻塞。优先完成这张卡背后的真实运行链，不以更多说明、测试数量或重复零单研究报告代替交付。支持用户交易理解与条件准备，但在R2及真实账户适配完成前不称为可直接照做的实盘指令，不为满足成果展示而强行产生买点。

### 首例R1完成判定

P1必须至少有一个明确日期/范围的适用模拟模型；“不适用”结论可完成研究审查，却不能算R1。P2须有真实资料连续窗口的逐日记录和合成边界验证，窗口按输入完整性预登记，不能按买点或收益挑选；允许今天设计的确定性政策用逐时点可用输入进行历史重建并承认后见设计偏差，不能把当前参数点值或新披露复制回过去。事后情景不替代点时决策回放。P3须有实际行情输入、持久化账户、幂等重跑和原表证据。三项全部满足才记录首例R1交付。

原表的同一公司应能看到：企业/价格/风险/账户各项满足与否、买入及加减仓触发条件、当前拟变动数量与资金、退出和再入场规则、证据入口。自然零单可验收；无适用模型、全部执行被硬编码禁止或账户被固定写死为初始值不能验收。账本经真实运行后因无交易而保持初始余额是合法结果。完成后按第7节推进，未完成项在运行记录中逐条保留，不用测试数量或笼统完成百分比代替。

## 5. 数据缺口和停止规则

本节的外部数据等待、工程/生产状态拆分、Snapshot 回放、ModelValidity 与
PriceBridge 规则，以 [外部数据阻塞处理政策](external-data-blocking-policy.md) 为准。
真实数据未形成时标记 `PENDING_EXTERNAL_DATA`，继续不依赖该数据的工程主线；
不得将此类等待标记为整个项目 `BLOCKED`。

## 7. 后续模拟扩展与实盘评审

三公司的研究展示和估值已在阶段 A/B 依次推进；随后交付茅台R1及限制，再将模拟规则、执行与账户验收依次扩展至美的、神华和三股组合。分别检查制造业再投资/业务增长及周期正常化，不把前一公司的参数直接复制。随后完善月度多通道初筛、6至10家公司研究及每日持仓跟踪；资产折价另建资产可回收与催化/等待成本证据后再试点，困境反转及特殊情形保持专项未支持。公司不适用或实验结果不佳时保留该结论，不为完成数量硬凑买点。

每条新增路径登记适用范围、选样依据、分析契约、规则版本和停止条件，再验证功能与经济表现。研究样本需含不入选、失败或具有相反证据的案例；冻结选择规则，保留排除理由和全部结果。首例或三家成功案例不能证明全市场筛选能力；有限案例不宣称统计有效，扩大筛选范围时另处理幸存者偏差与退市记录。

日常模拟通过第4节条件后即可开始该范围的真实会话前瞻记录，无需等待历史窗口、R1或其他股票。继续完成历史窗口及R1，再按上述顺序扩展；沿途补全既有2015-2025协议、同口径基准、历史费用及公司行动，以及加密备份和隔离恢复。30个会话衡量运营可靠性，不自动证明收益稳定；研究no_order摘要不计作完整日常模拟会话。

收益评估先报告税费后绝对收益、回撤和现金占用，再与同股买入持有、相同预算/敞口政策的买入持有加现金、可取得的宽基/行业全收益基准比较。100万元、单股8%的策略不能只靠比满仓回撤小就被认定有效。主用途、比较口径和允许的权衡须在本实验收益输出前登记；不把预测收益、少量交易或无交易的零回撤当成稳定收益证据。

R2保持技术、数据范围、经济证据、运营及真实账户五方面的适用性验收。历史范围不足或结果不确定时缩小结论范围，不能把少量交易、合成收益、单次盈利或页面完成当实盘准入。

项目交付与投资结果分别判断：每个阶段登记范围、交付物、通过条件和下一触发事件，R1、三股/组合扩展、R2评审分别完成。R2评审允许形成通过、证据不足或不通过的明确结论，后两者不是实盘就绪，也不要求无限调参直至盈利。全市场历史有效性是另有身份池及退市样本要求的研究，不是限定股票的所有功能必等的前置条件；未完成时不得宣传通用选股收益。仅有一份不准入报告而约定业务或运维仍未完成，不能宣称整个项目完成。
