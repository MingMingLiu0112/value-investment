- R1 指定范围模拟：不成立。主模型未被准入；历史执行已完成官方交易日、官方停复牌查询和价格限制筛查，但仍缺下一开盘订单簿、队列、成交成本或可成交性证据。服务器同步已恢复，但只是运营链路。
- R2 人工小额实盘：不成立。除 R1 缺口外，尚无真实账户、风险预算、券商费率与交易权限的适配验收。

## 后续顺序

1. 对 P1 只追踪能够改变工业/金融边界、权益桥接或匹配人民币经营资本成本的原始披露。没有新证据时不反复生成同一敏感性或选择便利折现率。
2. 将现有金融公司、内部存款、抵销和共享成本证据整理为一个可复算的保守边界契约；只有该契约能避免双重计量且其影响可定界，才重跑主模型与权益桥接。
3. P1 通过后，补齐历史逐日开盘订单簿、队列、费用与可成交性证据；官方交易日、官方停复牌查询、日线和涨跌幅筛查已完成，但只能作为拒绝不充分证据的保护层。再以冻结规则运行 R1 范围的前瞻纸面跟踪，不能用既有零订单或两笔合成成交替代这一步。
4. 仅在 R1、数据范围、经济证据、运营可靠性和账户适配均通过后，再讨论 R2；首例前不扩展美的、神华或三股组合来回避茅台的未决结论。
5. 服务器根盘恢复到至少“2GiB 保护余量 + 本次演练估算写入量”后，才运行已有隔离恢复演练；届时核对 dump、原始证据 Hash、关键表行数/Hash，并记录实测 RTO/RPO。不得以清理证据、降低保护余量或挤占 PTA 内存来制造通过。

## 计划合理性

当前计划保持合理：将不依赖估值准入的执行和发布机制先做到可重复、可审计，避免 P1 未解决时硬造订单。服务器密钥与一次真实同步已完成，下一阶段的唯一主要约束是工业/金融范围、权益桥接和匹配的人民币经营资本成本的证据质量，而不是更多代码、更多估值网格或更多回测运行次数。任何把条件值升级为买卖价的推进都将与当前证据冲突。
