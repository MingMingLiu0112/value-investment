# 早期沪市费用实验接入

日期：2026-09-09。适用范围：2015-01-01至2015-07-31的沪市现金股票研究。不是券商真实收费验证。

既有 `DatedResearchCommission` 默认仍拒绝早期沪市成交。增加四个必须完整提供的可选参数：`legacy_face_value_per_share`、`legacy_broker_rate`、`legacy_broker_minimum`、`legacy_basis_ref`。前三个为显式Decimal，最后一个指向调用方记录的面值依据和券商收费假设；组件验证参数格式，不证明该引用的真实性。

早期计算为成交股数绝对值乘每股面额，交给既有法定费用函数按中国结算0.3‰计费；另加 `max(成交面额×假设券商留存率, 假设券商留存最低费)`。普通佣金及卖出印花税分别计算，不按市价代替面额。2015-08-01起不再应用旧留存参数，使用既有按成交额计费规则。

结果保留实际成交日期、面额基数、留存费及假设引用，`full_cost_verified=false`。历史费用准确性、舍入及经手费内含政策没有因此自动通过；不得将调用成功宣称为真实完整成本。0.3‰券商留存率及1元面值目前仅出现在明确标注的合成测试，未作为茅台事实使用。

本轮检索2014原年报 `runtime/historical-filing-index/20260908T041326996681Z/pdfs/600519-1200877315.pdf` 的“面值”，仅命中一般会计政策，不能证明公司每股面额。下一步通过当时公司章程、发行原件或股本与股数的同口径披露核定。券商费率无法取得历史个人账户数据时，登记多组完整费用假设做敏感性，不声称还原该用户真实交割单。

验证：`tests/test_research_commission.py`及`tests/test_research_commission_legacy.py`，18项通过，包含默认拒绝、面额与成交额分离、留存最低费、卖出税费、制度切换、非法/不完整参数拒绝。全部为组件/合成测试，不是2015—2025策略收益或经济验收。

整体目标继续进行。没有修改原Excel、服务器、PTA、持仓或实际交易。
