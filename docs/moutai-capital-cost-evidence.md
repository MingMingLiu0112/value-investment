# 茅台资本成本证据与适用边界

更新：2026-09-22。以下是研究证据，不是批准WACC；不改变原Excel的买卖门禁。

## 为什么优先检查资本成本

完整条件股权模型648组的匹配分析显示，在当前实验范围内，联合回报率变化造成平均每股436.84元的试算差异，经营情景为370.74元。该分析同时改变工业、财务公司和少数股东权益的回报率，不能将全部差异称为纯工业WACC效应。平均幅度不是概率加权预期或置信区间。

## 公司自身历史关系

复用已核验的2015至2025年2674个交易日行情及15次分红送转原件。构造税费前、除权日收盘按碎股理论再投资的股票收益序列；其每日总收益因子为`[当日收盘价×(1+每旧股送股数)+每旧股现金权利]/前日收盘价`。实际现金尚未到账也在除权日按权利再投资，因此是研究收益尺度，不是可执行账户。使用实际每合格股分红，不能用不同股本分母的除权参考金额替代。

与H00300官方全收益在同一股票回测日期对齐，按月末观测计算月收益。排除缺少上年12月末起点的2015年1月，只使用2015年2月至2025年12月131个完整月。回归有截距，输入为原始收益而非扣无风险利率的超额收益；截距不解释为策略alpha。

| 样本 | 月数 | 股权收益斜率 | R² |
| --- | ---: | ---: | ---: |
| 2015年2月至2025年12月 | 131 | 0.9875 | 0.4630 |
| 2015年2月至2019年12月 | 59 | 0.8886 | 0.4645 |
| 2020至2022年 | 36 | 1.3296 | 0.5259 |
| 2023至2025年 | 36 | 0.8807 | 0.5610 |
| 截至2025年12月的60个月 | 60 | 1.1030 | 0.4951 |

所有分红收益因子经独立碎股数量法复算；五个回归斜率经Decimal协方差/方差复算，和NumPy最小二乘一致。未计算稳健置信区间，也不以样本内R²批准预测用途。

## 与行业参数的关系

已有2026-01-05学术行业资料给出中国酒类现金调整无杠杆Beta约1.6925、全球约0.7250。区域样本重叠、业务组合和市场基准不同，不进行简单平均。上述公司历史股权斜率也不能与这些无杠杆业务参数直接并列选一个“看起来合适”的值。

公司股权含金融子公司、现金、融资和权益结构；从上市股权推导工业经营风险，仍须明确业务资产范围及市场价值权重。当前回归截止2025年末，不是2026年9月最新风险参数，更不能将全样本结果回填2015年的决策。原6%/8%/10%保留为联合实验回报率，不宣称8%已获公司资本成本批准。

## 下一步收敛

先定义工业、金融及少数权益各自现金流与回报率对应关系，核定风险参数所用市场及去现金/去杠杆方法；用当前可得资料和历史窗口分别检验，不把旧期股价关系当稳定常数。原始基准仍需独立数值和方法核验。长期量价、利润率及终值再投资假设与资本成本同时评审，不能通过降低折现率来制造买点。

## 2014 专业评估披露的 ERP 观察：仅研究栅格，仍未批准资本成本

评估说明。报告日期为 `2014-10-14`，评估基准日为 `2014-07-31`，披露 URL 路径日期
为 `2014-10-24`，PDF 创建元数据为 `D:20141023173556Z`。原文显示，该项评估选取

指数 `2001` 至 `2013` 年几何平均收益法的算术平均得到 ERP `7.47%`。

该项评估的被评估单位是台州市亚东水泥制造有限公司，并非贵州茅台。因此原文中的
