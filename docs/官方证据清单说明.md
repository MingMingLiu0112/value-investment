# 官方证据清单

将交易所公告或公司 IR 年报 PDF 保存到本目录的子文件夹，再在同目录新建 JSON 清单。每份清单只对应一个原始文件；`fair_value` 是人工研究结论，必须勾选 `human_reviewed: true` 才会进入估值计算。

```json
{
  "source_name": "上海证券交易所 / 公司年度报告",
  "source_url": "https://www.sse.com.cn/disclosure/listedinfo/announcement/",
  "source_type": "exchange",
  "published_at": "2026-03-30T18:00:00+08:00",
  "evidence_file": "600519-2025-annual-report.pdf",
  "parser_version": "manual-evidence-v1",
  "validation_status": "verified",
  "human_reviewed": true,
  "reviewed_by": "your.name@example.com",
  "reviewed_at": "2026-09-02T10:00:00+08:00",
  "points": [
    {
      "symbol": "600519",
      "field_name": "roe",
      "period_label": "2025-12-31",
      "value": "35.20",
      "unit": "percent"
    },
    {
      "symbol": "600519",
      "field_name": "fair_value",
      "period_label": "2026-09-01",
      "value": "1600",
      "unit": "CNY/share",
      "calculation_method": "DCF",
      "calculation_formula": "discounted owner earnings",
      "assumptions": {"discount_rate": "10%", "growth_rate": "4%"},
      "valuation_as_of": "2026-09-01"
    }
  ]
}
```

已验证的交易所来源仅接受 SSE、深交所或巨潮资讯网的 HTTPS 公告地址。公司 IR 原文请使用 `"source_type": "company_ir"`，并额外提供与 `source_url` 主机完全一致的 `"company_ir_domain"`。已验证证据必须包含复核人和复核时间；合理价值还必须包含计算方法、公式、关键假设和估值时点。缺少任一项时导入会被拒绝，不会影响数据库或 Excel。

导入命令：

```powershell
python -m value_investment_agent import-evidence --manifest docs/evidence/600519-2025.json
```

导入后运行 `python -m value_investment_agent update --prices --financials` 重新计算。系统会把原始 PDF 的 SHA-256、链接、发布时间、人工复核状态和计算公式输出到数据库与 Excel 审计页。只要行情或合理价值未核验，信号仍会保持为 `待数据`。

## 财报候选提取

对已归档的交易所 PDF，可先运行以下命令生成只读候选包：

```powershell
python -m value_investment_agent extract-filing-candidates --pdf path\to\report.pdf
```

批量任务会把候选字段、数值、页码、原文片段和 PDF 的 SHA-256 保存到数据库，并同步到 Excel 的 `14_财报候选`。这些行的状态固定为 `candidate_requires_human_review`，不是正式财务数据，不能用于估值或买卖信号。

复核时应在原始公告 PDF 的对应页逐项确认公司、报告期、单位和数值。确认无误后，按本说明的 JSON 清单格式把确认值以 `human_reviewed: true`、`validation_status: "verified"` 导入；导入时必须保留同一公告 URL、原始文件和 SHA-256。解析候选只用于提高定位效率，不能替代该人工确认步骤。当前候选范围包括现金、部分有息债务、经营现金流、资本开支，以及年报摘要中的收入、净利润、EPS、ROE 和每股净资产；银行报表仍需按银行专用口径复核。
