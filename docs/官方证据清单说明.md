# 官方证据清单

将交易所公告或公司 IR 年报 PDF 保存到本目录的子文件夹，再在同目录新建 JSON 清单。每份清单只对应一个原始文件；`fair_value` 是人工研究结论，必须勾选 `human_reviewed: true` 才会进入估值计算。

```json
{
  "source_name": "上海证券交易所 / 公司年度报告",
  "source_url": "https://www.sse.com.cn/disclosure/listedinfo/announcement/",
  "published_at": "2026-03-30T18:00:00+08:00",
  "evidence_file": "600519-2025-annual-report.pdf",
  "parser_version": "manual-evidence-v1",
  "validation_status": "verified",
  "human_reviewed": true,
  "points": [
    {
      "symbol": "600519",
      "field_name": "roe",
      "period_label": "2025-12-31",
      "value": "35.20",
      "unit": "percent"
    },
    {
      "symbol": "600519",
      "field_name": "fair_value",
      "period_label": "2026-09-01",
      "value": "1600",
      "unit": "CNY/share"
    }
  ]
}
```

导入命令：

```powershell
python -m value_investment_agent import-evidence --manifest docs/evidence/600519-2025.json
```

导入后运行 `python -m value_investment_agent update --prices --financials` 重新计算。系统会把原始 PDF 的 SHA-256、链接、发布时间、人工复核状态和计算公式输出到数据库与 Excel 审计页。只要行情或合理价值未核验，信号仍会保持为 `待数据`。
