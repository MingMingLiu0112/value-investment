# Excel 前端设计评估与本次调整

评估日期：2026-09-12。依据 `value-investment-goal-prompt.md` 最新执行契约、`value-investment-goal-framework-v2.md` 第10节，以及原工作簿和已归档运行证据。

## 客观结论

调整前的表格是研究资料台账，尚不满足完整的价值投资选股、每日跟踪、交易指导和仓位闭环。它已有大量数据与研究成果，但缺少可靠的导航、简洁的行动入口及可执行交易建议。页面变漂亮、研究回放成功、零订单账本闭合，都不能替代模型适用和策略验收。

## 发现与处理

| 问题 | 实际依据与影响 | 本次处理 |
| --- | --- | --- |
| 表内跳转格式错误 | 原文件3,795个外部关系中，3,788个实际是以 `#` 开头的工作表引用，却写成 `TargetMode=External`。WPS尝试打开外部文件。前一轮只校验了目标单元格，未验证保存格式。 | 改用OOXML的内部 `location` / WPS `SubAddress`；普通网页保持外部URL。增加保存格式回归及WPS实际跳转验证。 |
| 工作表层级过多 | 28页中21页可见，日常动作、研究明细、审计和旧资料混排。 | 6个日常页在前，4个参考页在后，其余18页隐藏保留，不新增工作表。 |
| 首页只有使用说明 | 用户仍需跨多页寻找一家公司当前应做什么。 | 首页直接显示茅台的报价日期、财报期、条件区间、研究行动、触发条件及持仓信息，然后提供六步导航。 |
| 主要案例与估值明细脱节 | 茅台不在当期初筛名单，估值表未包含它；大量其他公司虽有行，但没有正式合理价。 | 在原估值页补入茅台的已归档日期快照；条件三情景单列，正式合理价和安全边际仍为空，不伪造准入。 |
| 研究状态与交易状态混淆 | 已有一家公司研究回放，但没有完整策略验收；部分候选的日常记录为过期或缺失。 | 已运行研究和742家待完成公司分开；待完成名单显示原决策记录的数据状态，案例页分开解释研究、交易条件与账户。 |
| 样式和阅读宽度不一致 | 首页是新样式，研究、估值、交易页沿用不同字体、表头与列宽，部分页宽达30列。 | 统一字体、标题、表头、冻结列及缩放；低频指标和技术列分组折叠，原值、公式、注释和历史保留。 |
| 本地文件链接不适合多设备 | 使用说明链接到D盘JSON，其他电脑未必有同一路径，也未必关联打开程序。 | 技术档案改为可读路径和Hash，不再伪装成跨设备入口；公司原始公告仍提供网页链接。 |

## 与最终目标的差距

| 目标能力 | 当前能做什么 | 仍未完成什么 |
| --- | --- | --- |
| 价值选股 | 查看已有初筛与研究进度，保留候选外的固定研究案例。 | 初筛入选不是买入推荐；最新目标的行业适配筛选、评分和完整模型不能因表中有公司就视为通过。 |
| 个股跟踪 | 茅台展示指定日期报价、报告期、条件研究和主要反证；其他公司显示其原有跟踪状态。 | 本次不刷新行情。可靠每日跟踪仍取决于采集、日期、规则运行与运营记录，过期记录不能当今日判断。 |
| 买卖与加减仓指导 | 展示目标条件、当前观察状态、不满足原因和拟单是否生成。 | 当前没有已验收的完整触发价、买卖数量与目标仓位。需关闭适用模型、完整决策账本及执行验证缺口；不能仅加文字或翻转布尔值。 |
| 仓位管理 | 保留人工账户记录，展示独立历史研究账户的期末现金、股数和净值。 | 模板100万元不是已确认的真实本金；未知持仓不能当零，也不能按条件试算直接卖出。 |
| 策略评价 | 已有真实历史输入的研究回放、零信号反证及独立实验记录。 | 现金锚、条件DCF和PE实验不能拼成同一已验证策略；完整历史基准、前瞻运行及真实账户适用性仍需分别验收。 |

## 固定阅读结构

日常：`00_首页Dashboard`、`00_公司总览`、`00_待完成公司`、`21_决策验证`、`05_仓位管理`、`08_交易记录`。

参考：`09_公司研究`、`04_估值跟踪`、`18_指标证据`、`00_使用说明`。

原有财务、评分、月度跟踪、复盘、审计、市场覆盖、配置及历史视图仍保留，可按需取消隐藏。首页和案例负责短结论，参考页保存长文与证据；不让读者用几万行审计日志寻找当天行动。

本次仅修复前端与展示契约，不改变金融阈值、估值批准、模拟准入、实盘准入或交易引擎。后续应优先完成目标MD指定的首家公司适用模型和统一决策账本，再扩展公司范围。
