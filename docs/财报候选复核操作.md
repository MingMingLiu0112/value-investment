# 财报候选复核操作

`14_财报候选` 中的行是自动解析的候选，不是已核验的财务事实，不能直接用于估值或交易建议。

1. 导出复核表：`python -m value_investment_agent export-review-template --output runtime/财报候选复核.csv`。
2. 在 Excel 打开 CSV，逐页核对原始公告 PDF 和摘录；仅保留确认正确的行，填写 `confirmed_value`、`confirmed_unit`、`reviewed_by`、`reviewed_at`，并将 `approve` 填为 `yes`。
3. 导入复核结果：`python -m value_investment_agent import-candidate-reviews --csv runtime/财报候选复核.csv`。

导入逐条检查候选 ID、数值、单位、报告期、官方 URL、SHA-256 与服务器归档文件的实际哈希。任意差异都会拒绝该批导入。成功后的数据才进入 `data_points`，并保留候选 ID、页码、原始标签、复核人和复核时间。

银行、保险、券商在官方行业分类和专用指标完成复核前，只能显示“专用模型待核验”，不得使用通用企业的现金流、负债率或 EV/EBITDA 规则形成交易建议。
