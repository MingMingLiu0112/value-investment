# 历史公告日期级可用性

2026-09-08。本轮解决只有公告日期、缺精确时分秒时的保守研究选择，不证明策略有效性。

## 规则

- 精确时间戳继续使用已核实的发布时间及可用时间，晚入库不覆盖较新的披露版本。
- 日期级公告只能在发布日期被核实、保守上界方法被核实且财务数值本身通过验证时使用。上界固定为中国时区公告日结束后的零点，不把原始接口中的默认零点当作真实发布时间。
- `available_at`不得早于上界，可以因额外处理延迟而更晚。实际成交仍必须遵守后续交易时钟，零点可用不代表零点可交易。
- 同一日日期级版本与精确时间版本可能无法确定先后。如果这些未能证明先后的版本数值或单位冲突，继续拒绝，不按输入顺序、入库时间或默认零点猜测哪个版本最新。
- 次日零点的精确披露可以确定晚于上一日日期级披露。后出更正不回填到历史决策。
