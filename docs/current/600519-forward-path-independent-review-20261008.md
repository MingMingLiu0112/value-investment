## 4. 终端与衰减：可以现在接受什么解释

### 4.1 全体资本回报归于成本，不等于只限制新增资本回报

`terminal_roe = cost_of_equity` 是一个明确、可复核的“无永久超额收益”条件，允许用于压力分析，无需证明竞争优势恰好在第十年消失。五年显式期和五年衰减期可作为有限研究窗口；不能仅因为保守或便于计算，把它们升级为最可能持续期。

其机制必须说清：存量品牌/渠道利润贡献衰退、资本分母因留存扩大，两者共同使**全体**资本平均回报靠近成本。仅说新投资回报低，不能解释 base 从第五年 813.67 亿元降至第十年 277.92 亿元；若存量盈利保持而留存只是低收益积累，利润不一定产生该降幅。原件不能识别这些利润贡献，所以这仍是压力机制，不是财报证实的归因。

可直接用于 `forecast_roes_5..9` 的 rationale：

> 在第五年之后，条件设定存量经营利润贡献受侵蚀且留存资本扩张，全体归母资本的平均 ROE 线性降至权益成本。这会产生已列明的 52.65%-75.35% 利润下降，不能解释为仅新增资本回报下降。五年衰减是有限压力窗口，不是确切护城河年限或中性预测；当前原件支持现有盈利与资本起点，不识别该未来归因。

反例与局部重开：若 Root 的当前产品/渠道研究能够解释稳定现金利润的来源和可延续机制，则“全体利润如此大幅衰退”与该论点存在张力，应重开 `forecast_roes_5..9` 的压力适用范围/主情景选择，而非要求先等十年。若新增证据只证明新资金低回报，则优先重开资本回报解释，不能自动认定整项存量优势灭失。衰减 0/10 年已在既有 policy 敏感性中注册；R1 可审阅现有结果的敏感性含义，不必新增模型或重新索取原件。

### 4.2 终端 2% 增长与留存的实际相容性

代码 [终端公式](D:/GPTProject/value-investment/src/value_investment_agent/valuation_models/residual_income.py:151) 为：`RI_terminal = (ROE_terminal - k) * B_10`，`retention_terminal = g / ROE_terminal`，`D_11 = (ROE_terminal - g) * B_10`。三个场景都满足 `0 <= g < k`、`g <= ROE`；终端增长来自终端留存，不借用未声明的股东外部资本。

若坚持终端也只留存 25%，其自筹增长应分别是 **1.9252%/1.6893%/1.4535%**，不能同时称固定 2% 且永久 75% 分配。现代码选择调整终端留存，数学上已解决此关系；需要在 `retention` 与 `terminal_growth` rationale 中明确前十年和终端两个制度，**本轮不更改参数**。

可直接用于 `terminal_growth`/`retention` 的 rationale：

> 2% 为名义终端增长条件而非财报预测。十个显式年度留存 25%；终端按 g/ROE 自筹增长，实际分配率随场景降至约 74.03%/70.40%/65.60%，不承诺永久 75%。若要求永久分配率固定，须在同一模型的新版本中联动审阅 g 与终端 ROE，不能只改一个标签。

终端 ROE 恰等于 k 时，终端剩余收益现值为零，给定显式路径和 k，改变合法范围内的 g 会通过留存/分配抵消，**不会改变剩余收益估值**。这不表示实际增长无关：它是无超额回报终端的结构结果。将这种“不敏感”当作已证明终端稳健、或靠调 g 来抬高该条件估值，均不成立。独立 R1 应现在确认此解释；不需要搜集确切未来增长事实。

### 4.3 零终端超额价值仍有尾部现金流条件

既有诊断中的终端股息现值约占股息交叉估值 **37.89%/36.91%/36.01%**（[diagnostic](D:/GPTProject/value-investment/runtime/company-research/600519-current-assumption-diagnostic-20261008T090508Z/evidence.json:29)）。零 RI 尾部与非零股息尾部可以同时成立；终端账面资本按成本回报继续经营，不是清算、无损变现或永久可随时提取现金。

`terminal_roe` rationale 应补：

> 终端无超额收益但仍假设剩余归母资本具有持续经营和股东分配价值。财务公司限制、基金损失、资产减值或资本不能按该回报使用，不由“ROE=k”自动覆盖；当前保持有界未知，若出现影响资本起点、利润或可分配性的新量化事实，则局部重开相关资本/利润/分配假设及现有重大性判断。

不从“风险可控”推出尾部无风险，不把既有零未来收益/零回收极端场景当成损失概率。`cost_of_equity` 本轮未独立复核，不按未知风险任意加点，也不为了对齐市场价格调低。

### 5.2 留存增加资本并不自动带来利润增长

base 前五年利润不变而每年留存约 203.42 亿元，五年末资本约 3,529.62 亿元。该条件可以解释为资金积累/较低增量回报、以及存量贡献变化抵消新投资贡献；**不能从这条构造路径识别新增资本的实际回报为零**。相反，若另称所有留存持续赚正向稳定回报且存量利润不衰退，则恒定利润路径与该论点不相容。现在应选择并说明条件机制，不需要制造新增收益率或等未来结果。
