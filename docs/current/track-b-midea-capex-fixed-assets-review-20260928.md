## 解释边界与 FCFF 影响

1. **可以确认的事实：** 公司持续购置设备、将已达可用状态工程转固，也有处置/报废；重大在建项目名称涉及创新中心、工厂、园区、车间及工厂翻新。FY2025 / 2026H1 的会计滚动表可按上述数值复核。
2. **必须保留 `UNKNOWN`：** FY2025 与 2026H1 的维护 CapEx、扩张 CapEx及其比例；各项目新增产能、替换/更新目的、预期回报；未来维持经济能力所需的正常化 CapEx。项目标题不是用途确认，资产折旧不是维护 CapEx 的代理，现金 CapEx 也不能与在建工程转固重复相加。
3. **不会改变 FCFF 适用性：** 这些明细让资产投资的发生额和转固/处置时点更透明，但没有拆出各经营分部和金融业务的 EBIT、税、投入资本、现金债务与营运资本，也未建立企业价值至上市普通股权益的桥。因此工业 FCFF carve-out 仍不能应用于当前披露范围；若未来范围桥接可支持，可重新评估其适用性。整体估值仍为 `MODEL_NOT_READY` / `VALUATION_NOT_READY`，本次不生成 FCFF 或维护支出估算。
4. **对模型假设的实际影响：** 它们反对“CapEx 可忽略”或“折旧等于维护投入”的未经证实假设。项目表出现工厂、创新中心、园区及翻新工程，说明投资构成可能混合扩建、能力建设和更新；但不够支持任何增长率、维护比例、ROIC 或现金流预测。`mature_manufacturing` 仅为宽泛经济画像，不能推出成熟企业的低增长或低 CapEx。
