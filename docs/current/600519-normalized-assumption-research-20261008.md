### 5.3 既有模型的合法约束与强衰减诊断

实际模型 [residual_income.py](D:/GPTProject/value-investment/src/value_investment_agent/valuation_models/residual_income.py:130) 使用**期初归母权益**：`income_t = roe_t * opening_book_t`，`closing_book_t = opening_book_t + retention * income_t`，`dividend_t = (1-retention) * income_t`。历史“利润/期末权益”可作首期盈利锚代理，但随后不能把同一历史高 ROE 直接复写为十个预测参数：留存、盈利与资本增加必须同时解释。

[当前 policy](D:/GPTProject/value-investment/runtime/company-research/600519-current-equity-policy-staged-20261008T090506Z/policy.json:74) 先假设五年利润增长 -5%/0%/+5%，据留存资本生成 ROE，再五年衰减到各情景权益成本。Base 即使利润不增长，25% 留存也使资本增加、ROE 下降；这不是已观察的竞争优势衰退。之后终端 ROE 等于权益成本使永续超额残余收益为零，是压力政策选择，不是年报证明的经济必然。

既有诊断（第 26 行起）显示显式期末盈利 → 衰减期末盈利（亿元）：Bear `629.60→298.10`（-52.65%）；Base `813.67→277.92`（-65.84%）；Bull `1,038.47→256.01`（-75.35%）。本轮只读取这些已有结果，没有重估内在价值。Bull 的终端利润低于 Bear 与其更低权益成本/终端 ROE 和资本路径有关；名称不是全时段盈利高低排序保证。这些降幅没有得到本轮原文的期限/量价/利润率解释，维持 `strong_fade_stress_scope_only_not_neutral_primary` 是可辩护的。

可确定的数理约束是：[校验代码](D:/GPTProject/value-investment/src/value_investment_agent/valuation_models/residual_income.py:106) 要求显式 ROE 非负、`0 <= retention <= 1`、`0 <= terminal_growth < cost_of_equity` 且 `terminal_growth <= terminal_roe`；[终端计算](D:/GPTProject/value-investment/src/value_investment_agent/valuation_models/residual_income.py:159) 使用 `terminal_retention = terminal_growth / terminal_roe`。因此当前 2% 增长与约 5.8138%-7.7006% 终端 ROE 对应约 **25.97%-34.40% 终端留存**，并非显式期的固定 25%。这些是公式相容性，不是发行人证据支持的经济预测边界。

本轮能给出的经济限制：新增留存资本不能默认获得存量品牌相同回报；必须区分可留存在现金/金融资产中的资本与支持经营的新增资本。高历史 ROE 不能充当前瞻下限，权益成本也不能自动充当企业终端 ROE；未披露提价销量/净利润与金融资金风险禁止主观中性化。**可靠未来 ROE 的数值上下限仍未知**，不凭历史最大值、当前股价或一个“保守”衰减标签生成。

### 6.2 回购与股东可分配现金

年报 p33 用于分红统计的回购金额 `6,120,088,960.04`，与 p68/p114 的回购现金和权益减少 `6,120,578,572.09` 相差 `489,612.05 CNY`；原文相关页未闭合差额原因，不擅认全为手续费。H1 p80 回购现金 `2,880,061,147.37` 与权益表净减少一致。注销金额包含期初库存股，不能再次记成一笔新增资本支出。固定未来股数的既有模型不得将历史回购含入现金派息率，又追加虚构未来回购提高每股价值。

合并归母未分配利润 `199,683,216,816.20`（半年报 p73）和母公司单体未分配利润 `107,646,565,355.82`（p30）不是现金余额。半年报 p73 明示一般风险准备 `1,061,529,724.00` 属财务公司准备；股东现金能力还受准备、受限资金、信用/流动性及上划约束。现有 75% 只能保留为条件性研究假设；“低于约 79% 的过去分红”不自动证明谨慎或未来可持续。
