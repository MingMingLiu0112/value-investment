# 项目现状说明（给用户的话，2026-10-16）

这份说明用大白话回答你最关心的问题。结论先放在最前面：

> 现在的系统已经是一个**能每天跑起来、讲得清"为什么先不买"的研究观察工具**，
> 但它还不是一个**能告诉你"买什么、什么价、买多少"的决策助手**。
> 这个差距不是我藏着没做，而是被三道真实的门卡住：没人签过字的估值、
> 没有你本人的账户和风险政策、以及策略有效性还没被验证。

---

## 一、现在真正能用的功能

- 每个交易日收盘后，系统自动从腾讯和新浪两个来源抓取六只重点股票以及全市场
  5,200 多只股票的行情，把你当天看到的数字和来源一起存档（原始字节带哈希，
  我这次逐一重新校验过，全部对得上）。
- 一个本地网页工作台（`http://127.0.0.1:8001`），七个页面：每日决策、个股详情、
  我的持仓、交易复盘、历史价格、系统状态等。这次我按四个屏幕尺寸（电脑大屏、
  普通笔记本、两种手机宽度）逐页检查，21 项检查全部通过，没有排版溢出，
  也没有把旧数据当成今天的数据展示。
- 每日决策页会告诉你：研究截止到哪天、行情是哪天、哪些是"研究观察"、
  哪些条件没满足、为什么没满足。例如伊利股份现在显示的是
  2026-10-16 收盘 28.20 元，条件区间 9.80 / 10.08 / 10.30，
  但明确写着"尚未获准，情景不是买价"。
- 全市场漏斗每天在跑：5,573 只股票里筛出 114 条研究线索（今天正式准入仍是 0 家）。
- 私人组合功能已经完整做出来了（记账、成本、T+1、可卖数量、双资金池风险、
  行业集中度、现金底线等），但它现在是**锁着的**：只有你本人在电脑上打开
  一次性授权链接、输入你自己的真实现金和持仓，它才会开始工作。
  在你输入之前，它绝不会替你编造一个账户。

## 二、哪些还只是"模拟/演练"

- "人工审批"目前只有一半：系统里有审批的数据结构和命令行工具，
  但网页上还没有正式的签字入口（这是我下一阶段要补的）；
  另外仓库里还留着几条 9 月 23 日由脚本生成的、名字像"人工批准"的记录，
  它们不是真正的批准，我会在下一阶段清理并加上拒绝校验，防止将来被误读。
- "AI Agent 分析"目前只在模拟模型上跑通过（`MOCK`），
  还没有真的调用大模型做过研究对照（没配置密钥，也没必要急着配）。
- 热点波段的"历史回测"只是描述性统计（比如触发后 5 天失败概率），
  没有算手续费、滑点、涨跌停买不进、停牌卖不掉这些真实约束，
  所以它现在**不能**作为策略有效的证据，我也不会把它说成有效。
- Excel：正式的那份 Excel 停在 2026-10-01 的快照（10 月 12 日发布），
  而网页已经更新到 10 月 16 日。两个界面对不上，这一点我会在下一阶段明确处理。

## 四、今天能看到什么投资判断

- 价值端：茅台和伊利两条"研究观察"，带条件区间、主要风险、下次复核事项，
  并明确写着"情景不是买价"。
- 热点端：中国船舶、航发科技、内蒙一机、洪都航空、航发动力 5 条观察，
  全部是 `WATCH`，其中 4 条明确"不符合当前入场条件"（结构冲突或空间不足）。
- 明确没有的：任何买入/加仓/减仓/退出指令；任何仓位建议；任何点位授权。

## 五、为什么现在还不能给买卖建议

三道门，缺一不可：

1. **经济证据门**：估值要有审计过的正常化利润、投入资本回报、母公司可分配现金、
   有依据的折现率。现在这些是"有条件计算"，不是"可授权结论"。
2. **人工审批门**：需要一个真人（也就是你）对"模型+事实+假设+版本"签字。
   系统可以准备材料，但不能替你签。
3. **你的账户门**：没有真实资金和持仓，任何"买多少"都是编的。

系统现在对这三道门采取的是"宁可不出结论，也不出假结论"的策略——
这正是它值得信任的地方，但也是你感觉"没什么用"的原因。

## 六、你的个人账户能不能接

能。功能已经写完并且测试过 43 项连续性/风险用例，包括 T+1、部分卖出、
双资金池、行业上限、现金底线。缺的不是代码，而是**你的一次性输入**：
在电脑上打开授权链接，录入真实现金、持仓、成本和投资政策。
你什么时候愿意做这一步，系统就能开始算你的个性化风险。

## 七、距离"第一次真正有用"还差什么

按重要性排序：

1. 把一家公司（我建议从**美的**开始）的经济输入补齐、跑出草案估值；
2. 在网页里做出真正的"人工复核签字"入口（含事件材料性、价格政策），
   并把机器生成的假批准记录清理掉；
3. 你完成一次真实的账户 + 投资政策录入；
4. 处理"老旧并行系统"：三个 Moutai 计划任务和服务器数据库管线还在写状态，
   要统一成一条链路；
5. 给数据上保险：现在所有验证记录只存在这台电脑上（`runtime/` 不在 Git 里），
   要做一次真正的恢复演练。

## 八、下一阶段为什么选这些任务

因为它们是**最短路径**：第 1 项决定能不能有结论；第 2 项决定结论能不能被授权；
第 3 项决定能不能变成"你的"建议；第 4、5 项决定这套东西能不能长期安全地跑。
其他事情（更大范围选股、更多公司、Web 美化）都排在它们之后。
热点策略继续积累前瞻观察，但不会在验证完成前宣称有效。
