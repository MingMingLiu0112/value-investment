## 4. 金融贡献与负债范围：不以完整工业债务/ROIC为前置

Archimedes留存原件复核显示，FY2025/H12026合并吸收存款及同业存放分别为18,038,383,776.30/25,426,316,668.17元；当期+非流动租赁合计233,711,179.82/243,684,868.06元。观察到的融资义务小计为18,272,094,956.12/25,670,001,536.23元，**不是穷尽债务认证**。六项小计/总计勾稽零残差不把借款空白变成已披露零。

FY/H1存款业务利息费用175,775,959.12/76,587,662.57元，与财务费用中利息28,734,948.29/21,034,591.16元是不同项目。后者扣除租赁利息后仍有19,841,855.81/17,165,751.87元未识别；不据假定利率反算借款本金。其他流动负债实际主要为待转销项税，不得塞入存款融资。关联方存款包括合并范围外主体，不当然抵销。

**可审的范围判断：** 继续用一致合并归母盈利/权益的RI；不要求先得到工业ROIC，亦不为取得ROIC强行切FCFF。尚未分清金融/工业NOPAT、资本、税和平均余额，工业ROIC保持null。现有工业九桶债务验证器不能签本公司的“完整融资范围”，但这不等于RI公式不可执行。必须分开历史融资事实、持续金融净贡献假设、监管/资金回收风险。

当前收益不能证明巨大金融资产的损失/流动性风险不重大；不得因利息收益占比不高即批准金融尾部。重开只针对具体资产减损、存款流出/期限错配、金融监管资本或已生效上划限制、未识别利息的实质来源，不继续泛搜以等待“无风险”证明。

## 5. 分配与回收：哪些可提交判断，哪些具体否决

现在可以提出并审阅原90%分配/10%留存与一年延迟：母公司历史现金、实收投资收益、资本预算及基金承诺给出了可算起点；**它们并不证明这组未来政策最合适**。六个月总经营支出是分析缓冲政策，不是法定现金线；90%利润分配亦不表示每笔留存回报为零或未来每年必然分红90%。

不要求公司先披露五年逐日现金表。但若存在具体生效的上划限制、监管/少数股东权利冲突、项目支出/基金调用与预算不符、或法定可分配利润不足，必须拒绝该条件分配路径。若审阅者不接受全额次年回收，原生内核对持续受限不提供合法终端，输出UNSUPPORTED；不能把该分支伪装成TIMING_DELAY或只削减估值百分比。

首年24.727%左右边界只是固定盈利/支出下的现金恒等式，不是可接受延迟概率、完整安全线或法定规则。本包不重复开发该功能，也不凭它批准回收时序。未来单体净利映射至现金实现的简化及终端停止提取，必须与法律储备、章程/决议及债权人约束同组审阅。
