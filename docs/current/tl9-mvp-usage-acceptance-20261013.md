# TL9 MVP 使用验收说明（2026-10-13）

本文件是 TL9 MVP（统一每日公开数据包、一条命令、私人状态一致、公司页与
首页收敛、Windows 端到端验证）的用户使用说明与工程验收记录。它不构成
任何买卖建议；系统永久保持 `action=no_order`，所有结论必须人工复核。

## 1. 唯一启动命令

```powershell
pwsh -NoProfile -File D:\GPTProject\value-investment\scripts\current\run_daily_workbench.ps1
```

- 默认 `-Mode READ_ONLY`：重建统一每日公开数据包、打印摘要、启动本机网页
  工作台（`http://127.0.0.1:8001`）并打印一次性解锁链接；
- `-Mode SAFE_REFRESH`：先采集当日双源收盘行情并登记（幂等，已登记则跳过），
  再重建数据包后启动；
- `-NoServer`：只更新数据包并打印摘要，不启动网页。

退出码：`0=SUCCESS`、`2=BLOCKED`、`3=PARTIAL`。

## 2. 工作台地址与解锁

- 地址：`http://127.0.0.1:8001`（每日建议 / 我的持仓 / 历史判断）；
- 私人数据默认锁定。启动脚本打印的“一次性解锁链接”形如
  `http://127.0.0.1:8001/#unlock=<本次运行密钥>`；密钥只存在于本次进程的
  内存中，重启后失效，需重新运行启动脚本获取新链接；
- 未解锁时，任何私人数据都不会被读取，页面显示“已锁定（尚未解锁）”。

## 3. 每日使用顺序

1. 收盘后运行上面的唯一启动命令（或打开已有工作台）；
2. 打开 `/daily`，先看首屏“数据版本 / 研究截止日 / 已登记行情日 / 新鲜度 /
   正式准入 0 / 待人工复核 / 需要重新研究”；
3. 看“下一步怎么做（真实待办）”：人工复核项（G3 审批、事件材料性）与
   工程项分开列出；等待外部数据的项目单独计数；
4. 点开“研究状态与重新研究清单”，逐家查看研究截止日与已核验收盘日的覆盖
   关系；
5. 进入 `/decisions/{代码}`（如 `600887`）阅读：一句话结论 → 公司投资逻辑
   → 估值与行情 → 行动状态 → 风险与失效条件 → 下一步怎么做；
6. 需要台账事实时，解锁后的“① 持仓需要关注的事项”只复述台账记录；
7. 页面底部“证据与技术详情（可展开）”保留版本哈希与来源路径供审计。

## 5. 人工复核入口

- 待人工复核事项在 `/daily` 首屏“下一步怎么做（真实待办）”中列出；
- 公司页“行动状态与变化条件 → 当前阻塞”列出全部阻塞原因（已翻译）；
- 人工审批材料仍以现有正式审核流程（G3 等）为准，系统不提供代签路径，
  也不因为人工未审批而停止数据包更新与页面展示。

## 6. 常见状态解释

| 状态 | 含义 |
| --- | --- |
| 已锁定（尚未解锁） | 没有读取任何私人数据；不等于“未接入” |
| 尚未接入真实私人组合 | 已解锁且目录可读，但没有已确认的真实台账 |
| 已接入，风险输入不完整 | 台账已读取；双策略风险引擎缺少 IPS/现金底线等输入 |
| 研究仍在进行 | 研究已有部分批准（如财务口径），未走完全部门禁 |
| 需要重新研究 | 已核验收盘日晚于研究截止日，必须先重登记再比较 |
| 模型有效性未确立 | 重大事件与假设尚未复核，模型不能直接用于价格比较 |
| 行情已核验，但晚于研究截止日 | 双源收盘价已归档；只有研究覆盖报价日时才能形成价格判断 |

## 7. 断网或缺行情时怎么办

- `READ_ONLY` 模式不依赖外网：可继续查看已归档数据包与页面；
- 缺少当日行情时，`SAFE_REFRESH` 会保留上一份已核验记录，页面明确显示
  “尚无已核验收盘价”，不会用旧价冒充当日收盘；
- 数据包读取失败时页面整体 fail-closed，只显示失败原因，不沿用旧版本；
- 行情登记文件损坏时，页面显示“行情登记文件不可读（登记状态未知）”，
  不会被解释为“没有登记”。

## 8. 私人组合如何安全接入

1. 私人台账必须存放在仓库与云盘同步目录之外（默认
   `~/value-investment-private`，可用 `VALUE_INVESTMENT_PRIVATE_ROOT` 指定）；
2. 通过 `/portfolio` 页面或私有 API 初始化基线（账户口径、现金、持仓、
   成本、资金池分配）并人工确认，之后每笔成交按“草稿 → 人工确认”两步写入；
3. 台账为 append-only JSONL，逐条含 SHA-256 链与幂等键，损坏时整体
   fail-closed，不会静默投影错误持仓；
4. 在“只差真实 IPS/组合输入”时，系统只列出缺什么，不编造任何仓位数字。

## 9. 当前系统能做什么

- 一条命令更新并查看每日公开数据包（版本、日期边界、新鲜度、计数）；
- 逐家展示研究状态与“研究是否覆盖已核验收盘”；
- 归集真实待办（人工复核、工程、等待外部数据）；
- 公司页给出由真实门禁状态生成的一句话结论、投资逻辑、估值与行情、
  行动状态、风险与失效条件、下一步怎么做；
- 私有台账初始化、成交草稿/确认、对账、双策略风险复核（本地授权后）；
- 全部产物可追溯（来源 URL、SHA-256、版本与收据）。

## 10. 当前系统不能做什么

- 不自动下单、不连接券商、不产生订单；
- 没有真实 IPS/组合输入前，不给“买多少/卖多少”的仓位数字；
- 不把研究观察、低估值或高股息直接当作买入信号；
- 不伪造行情、财报、人工审批、回测结果或用户验收；
- 不自动覆盖唯一正式 WPS 工作簿（正式发布需独立授权）。
