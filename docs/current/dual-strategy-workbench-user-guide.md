# 双策略研究工作台

唯一正式前端仍是 WPS 云盘中的原 Excel。所有建议只用于本人复核，不会下单。

## 日常使用

在 PowerShell 7 执行：

```powershell
& 'C:\Users\we\AppData\Local\Programs\PowerShell\7\pwsh.exe' -NoProfile -File 'D:\GPTProject\value-investment\scripts\current\start_trade_workbench.ps1'
```

菜单选择打开工作台、更新并发布、扫描热点、查看组合状态或研究审核。更新默认处理已登记的两家公司，同时扫描热点、查询巨潮官方公告、生成风险状态，完成来源、数值、历史保护与 WPS 验证后发布原表。无实质变化不覆盖；失败原因保存在对应运行目录的更新回执。工作簿占用、云盘同步冲突或 Hash 变化会阻止覆盖。

## 七页入口

| 页面 | 看什么 |
| --- | --- |
| 01_今日 | 重点机会、风险、变化、下一待办。 |
| 02_机会 | 价值与热点观察分开列出，逐项看日期、状态及下一条件。 |
| 决策过程 | 经营、事实、估值、价格、组合及人工审核的前置状态。 |
| 03_公司 | 当前候选估值在前，旧研究单独标注；核对反证与买卖复核条件。 |
| 04_我的组合 | 两个独立资金池及风险；无本人输入时显示未接入。 |
| 05_事件 | 已分类事件与后续事项。新取得的原件不等于影响已批准。 |
| 06_系统与审计 | 原始来源、URL、文件 Hash 与可追溯的运行证据。 |

更新日期、研究截止和行情日期含义不同。上一个交易日收盘可以用于明确日期的观察；不能自动成为新模型的正式价格准入。

## 价值投资的操作条件

当前真实两家公司没有正式买卖候选。悲观、基准、乐观的条件研究数值不是买点，也不是已批准合理价值。

买入需通过研究、模型有效性、事件材料性和正式价格规则，再由本人核对组合容量。加仓还需原始论点及增量证据，不因下跌自动加仓。持有依赖论点连续性。论点削弱或失效、财务恶化、重大反证及集中度风险可触发减仓或退出复核；普通波动不自动等于卖出依据。公司页列出实际支持、反证及下一触发。

## 热点观察

热点扫描使用既有腾讯市场、新浪行业、双源报价和保留日线解析器。行业快照交易日不明时明确标注；部分证券有独立核验的报价日期，也不把该日期赋给整个行业。历史日线与近期报价分开，不用日线编造 60 分钟或 15 分钟数据。

目前可以看行业描述性强弱、相关证券、独立历史趋势、前高前低、关键价位与缺失条件。催化、持续性、复权及量能口径未验证时保持缺失。热点强度不能绕过既有价值、风险、时间点、样本外、成本及 Shadow 门禁，因此观察状态不等于入场资格。

## 本人资金与交易记录

核心价值和热点资金分别记录预算、现金、数量及已占用风险，不自动借用或转移。本人必须提供或核验政策、持仓、成本、现金、风险限额和来源；空白不是零。空模板不预填策略阈值。

已实现的验证入口是 `review_dual_sleeve_risk.py` 的私人 JSON 或 CSV 输入模式，使用现有 IPS/Portfolio 合同。实际输入与输出必须放在 Git 和同步目录之外的私人根目录，并绑定 Hash。不能将组合明细上传公共仓库。Excel 输入准备区与 CSV 模板的字段相对应；仅填写单元格不能代替完整输入验证或批准。

已验证的私人风险也可接入每日更新：先用 `--summary-preview` 查看仅含两资金池预算、现金和风险占用的摘要，本人确认后将该摘要 Hash 写入私人配置，再通过统一更新入口传入 `--private-risk-config` 与 `--private-risk-config-sha256`。配置和持仓原文不会复制进项目；汇总内容发生变化后需重新确认展示授权。这是资料展示授权，不是投资审批。当前菜单未配置任何私人账户，仍显示未接入。具体字段见 `dual-sleeve-private-release-minimal.md`。

风险结果分别检查现金、资金预算、行业及单票集中度、主题重复暴露。热点数量依据本人风险预算、每股压力损失、费用和现金限制取整，还受 T+1、流动性及涨跌停限制；止损价不保证成交。没有真实输入，不输出个人数量或收益。

手工 PLAN、FILL、REVIEW 使用追加的 Hash 链日志。计划不等于成交；成交必须由本人提供，不从候选估计。日志不自动改变持仓，持仓仍经核对流程更新。

## 审核与仍未完成的准入

菜单中的研究审核可阅读两家公司问题、支持与反证，保存未签名草稿或取消。正式信任根为空时不能消费真实批准。本人需先确认审核身份、公钥归属及精确权限，私钥由本人保管；整模型与公告材料性独立审核，旧模型批准不能迁移。

日常研究产品试用不等于 INITIAL_ASSISTED_USE。真实经济审核、G3、事件材料性、有效模型及正式价格、本人组合、生产授权、真实 Shadow、恢复验收和最终用户验收各自保持实际状态。连续真实会话及严格同时点证据不能由合成测试替代。完整收益稳定性尚未证明。

已知保留风险：原候选准备器在上海午夜至早上 08:00 的 UTC 日期编码与上海研究日期可能冲突，严格 PIT 会拒绝生成。当前两家公司每日更新直接使用已登记研究包，不经过新候选准备分支。跨午夜回归明确验证了这一缺陷及严格拒绝行为；旧源码受历史 Hash 绑定，本轮未修改，也没有声称已修复。
