## Consequences

The four-component borrowing/bond proxy does not establish comprehensive
interest-bearing debt. Financing within long-term payables requires separate
classification. Adding all note values would also double count current portions;
the mining-right payable cannot automatically be classified as financing.

Do not promote a zero bond value or mark this issuer's debt input complete on
this evidence alone. Keep the existing missing-debt gate. Extend debt scope
reconciliation across the candidate pool, including leases and financing payables,
before describing the proxy as comprehensive debt. Existing 9/9 model coverage
does not prove that wider debt-scope audit is complete.
