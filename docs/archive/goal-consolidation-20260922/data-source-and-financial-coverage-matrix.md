# 数据源与财报覆盖矩阵

更新：2026-09-20。本文是当前项目的数据获取契约，不把计划中的接口写成已接入能力。

## 结论

价值投资系统不应试图先把每一家公司的全部财报附注无差别解析完毕。那会产生大量无法可靠自动解释的文字、表格和会计判断，也不能自动形成内在价值。正确范围是：对每个公司、每一个模型，先定义必要字段；这些字段必须从可追溯的一手披露中抽取、校验并保留原件定位。结构化公共接口用于发现、补充和差异报警，不提升为正式估值事实。

当前 600519 已完成 2014-2024 年 11 份年度报告的归母利润、归母权益、基本 EPS、期末股数和公告可用时点核验；2025 年报、2025H1、2026H1 亦已归档并用于当前 TTM、权益、现金流及股本/资本事项研究。其余附注并未“全部解析完成”，也不应被错误宣称为完成。详细清单见 `moutai-financial-report-coverage-20260920.md`。

## 字段级契约

| 数据域/字段 | 正式主源 | 已接入的补充或交叉源 | 当前处理状态 | 可支持的用途 | 不足时的动作 |
| --- | --- | --- | --- | --- | --- |
| 年报、中报、季报原件及更正链 | 巨潮公告查询与 `static.cninfo.com.cn` 原 PDF；公司 IR、上/深/北交所披露按公司补充 | 无 | 已接入：公告 ID、URL、发布时间、PDF Hash、报告期与解析版本 | 所有正式财务事实的证据锚点 | 无原件、报告期或更正关系时，禁止将摘要数值升格为正式事实 |
| 合并收入、营业成本、归母利润、归母权益、总资产/负债 | 原 PDF 的合并三表及主要财务指标页，附页码、单位、表头 | AkShare/Sina 财务摘要、三表 | 部分通用解析已接入；候选值须和原件定位核验 | 质量研究、TTM、剩余收益/股权价值输入 | 单位、合并口径或重述关系不明时为待核验，不默认零或沿用旧值 |
| 经营现金流、资本开支、营运资本项目 | 原 PDF 合并现金流量表、资产负债表及必要附注 | AkShare/Sina 摘要 | 现金流、资本开支通用候选解析已接入；营运资本须按行业和模型补提取 | FCFF/现金回报、资本效率研究 | 不能安全重建时，不启用 FCFF；可改用匹配范围的股权模型或保持研究状态 |
| 有息债务、租赁、长期应付款、可转债 | 原 PDF 合并资产负债表及债务附注 | AkShare/Sina 摘要仅用于差异定位 | 通用字段候选解析已接入；复杂融资范围逐公司核验 | 企业价值到权益价值桥接、偿债风险 | 债务范围未知时阻断企业价值桥接与新增风险动作 |
| 分红、回购、注销、增发、A/H 股数及库存股 | 巨潮/交易所实施及股份变动公告；A/H 事项另核对 HKEX 月报/公告 | AkShare CNINFO 分红接口 | 分红历史及公告归档已接入；股本事件按时点单列 | 每股价值、总回报、股数时间线 | 不能用报表日股数直接覆盖交易日；资本行动窗口不完整时阻断每股结论 |
| 当前及历史价格、成交状态 | 腾讯/新浪公开报价和历史日线；交易会话以实际时间戳与多源核对 | AkShare/东方财富 | 已接入，公共源无 SLA | 条件监控、模拟会话、价格交叉检查 | 报价时间、会话或停牌状态不明时阻断精确订单与“今日”结论 |
| 无风险利率、权益风险溢价、资本成本 | 可复核的官方利率原件/发行版本；模型假设和选择政策独立归档 | ChinaBond 历史文件仅研究敏感性候选 | 当前历史时点可用性未验收 | 贴现率敏感性和研究 | 不能把后来修订的历史曲线回填为当时可知；阻断正式历史估值/回测 |
| 行业、商业模式、竞争与政策 | 公司年报、招股书、同行年报、统计部门/主管部门/行业协会原始材料 | GitHub 项目仅用于发现端点、分页和解析模式 | 逐公司研究，不假设聚合来源是事实 | 商业质量、反证、情景假设 | 未有可引用证据时显示“未知”，不得由 AI 评分替代 |

## 已部署与未部署的边界

- 已部署：CNINFO 法定披露发现/归档；原 PDF Hash 与页码证据；AkShare 所接公开行情、财务摘要/指标/三表和 CNINFO 分红；腾讯/新浪用于价格交叉核对；本地原件冷归档与 PostgreSQL 审计。
- 已研究但不应宣传为已部署：同花顺、Tushare 及付费终端；它们需要独立的授权、覆盖、版本和稳定性验收后才可成为生产候选。
- GitHub 项目（包括 `a-stock-data`、`go-stock`、`TradingAgents-CN`）可借鉴端点发现、分页、交易日历、研究角色和回测工程模式；它们不是法定披露源，不能因能返回数据而替代原始财报或证明历史可用性。

`docs/source-integration-v3.9.0.md`。该仓库本质上是数据端点与验证模式的
Skill 文档，非可作为本项目依赖导入的财务数据服务。可借鉴内容限定为：

- 对公开行情、公告和事件接口做分页完整性、日期、唯一性、空结果与异常响应的显式校验；
- 把腾讯、东财、中债等公共来源视为不同数据域的补充，而非同一事实的独立法定来源；
- 对来源限制保留可机器识别的失败状态，例如北交所覆盖、历史包起点、非交易日和静默空结果。

不得照搬或提升为本项目事实的部分：其记录的 `chinabond_yield_curve` 是当前可访问的
历史曲线接口，不含每个历史决策日的发布版本证明；因此仍不能用于本项目 R1 的点时
资本成本。其行情、研报、事件和宏观端点也不提供巨潮年报原件的公告 ID、PDF Hash、
页码或合并口径核验，不能替代本表第一行的法定披露链。项目应只复用已验证的端点合同，
由本项目适配器保存响应 Hash、抓取时间和本地验证结果；不直接复制外部实现或将外部
测试结论写成自身生产验收。

## 估值前的最小财报输入包

非金融企业的 FCFF 需要：合并收入、营业成本/税、经营利润或可重建 NOPAT、折旧摊销、资本开支、营运资本变动、现金及非经营资产、全部匹配债务/少数权益、普通股权益范围和股数。金融企业不可套用 FCFF，必须采用归母权益、可分配利润/分红、资本充足及专用股权/剩余收益模型。

每个输入都必须记录：`symbol`、`field_name`、`value`、`unit`、`period_label`、`source_id`、原件 URL/Hash、页码、公告/可用时间、解析器版本、校验状态和派生公式。只有全部必要项通过适用模型的字段契约，才允许输出指定范围的条件估值；正式合理价值、模拟订单和实盘辅助另受目标框架的模型、时点和执行门禁约束。
