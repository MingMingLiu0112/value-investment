# 茅台折现率：酒类行业Beta反证

## 取得的原始研究

纽约大学Damodaran公开页面 `https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/Betas.html`，页面明确为美国行业样本，数据截至2026年1月。原始HTML、表头、链接和Hash已归档在 `runtime/valuation-research/damodaran-industry-beta-20260909T120253277020Z`。

| 原始字段 | Beverage (Alcoholic) |
| --- | ---: |
| 公司数 | 14 |
| 杠杆Beta | 0.81 |
| 债务/权益 | 43.34% |
| 有效税率 | 12.35% |
| 去杠杆Beta | 0.61 |
| 现金/企业价值 | 2.37% |
| 现金调整后去杠杆Beta | 0.63 |

页面同时列出软饮料27家公司，现金调整后去杠杆Beta0.58；软饮料不是白酒，不合并计算平均值。该学术作者汇总多个数据服务，属于外部研究参照，不冒充中国公司原始披露或公司Beta观测。

## 对当前模型的影响

1. 之前0.8/1.0/1.2是假设敏感性网格，不能称其覆盖全部合理的经营Beta；原始外部酒类样本现金调整后值0.63在网格之外。保留旧实验，但不以其端点作为置信区间或硬下限。
2. 工业经营资产与现金分开估值时，应研究经营资产风险，而非直接使用含美国行业债务结构的0.81。重新加杠杆必须采用匹配的工业债务/市场权益，不使用财务公司吸收存款充当工业债务。
3. 表中12.35%明确为有效税率，不代表作者去杠杆计算使用的边际税率；不能为了得到0.61而悄悄换税率。原表各列独立保留，方法待作者变量说明核实。两位小数的列值也不能要求精确反算相等。
4. 美国14家公司与中国高端白酒存在市场指数、融资、酒种、渠道、政策和收入地域差异。此观察既不证明茅台Beta是0.63，也不证明Beta应当不低于1。
5. 单位国家风险加载也只是实验；国内收入占比不是经过验证的国家风险系数。现金流悲观场景与资本成本风险加成不得无解释地重复施压。

## 下一步执行

沿原页面给出的全球数据页和行业成分文件寻找全球/中国可比样本，核对计算方法、样本构成和剔除现金的处理，再形成明确的公司参数区间。若公司历史回归可用，需要明确对应基准、收益口径、时间窗与误差，并作为交叉验证，不能因拟合结果更有利就挑选窗口。

此时不新增估值批准、不更改生产交易阈值。期内现金流衔接、股权桥接及终值再投资仍须完成。避免继续堆积与这三个模型关键输入无关的附注。
