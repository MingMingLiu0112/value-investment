# 长期目标：A 股价值投资研究与跟踪系统

生效：2026-09-22。职责：产品方向，不直接授权开发路线图中的所有功能。
文档权威与读取入口见 [AGENTS.md](../AGENTS.md)；当前唯一任务见 [current-stage-goal.md](current-stage-goal.md)。

## 产品定位

面向 A 股中长期价值投资与持续现金回报需求，建设证据驱动、可追溯、多行业适配、事件驱动的投资研究与持续跟踪系统。
系统同时服务企业内在价值长期增长和可持续、可增长的股息现金流。用户希望逐步形成有经济依据的长期资本增值与现金收入来源，系统不承诺盈利、固定收益或分红必然持续。

后台逐步覆盖大规模股票池，收集并验证基本面证据，按公司经济特征选择研究与估值框架，研究现金创造、资本配置、企业价值和股东分配能力。通过持续更新事实、假设、反证、不确定性、价格与重大事件，只将少量真正值得研究的公司呈现给用户。最终投资决策由人完成。

## 六条投资研究路径

| 路径 | 核心问题 |
| --- | --- |
| Quality Compounder | 竞争优势能否持续转化为高回报再投资与每股价值增长？ |
| Dividend / Cash Return | 盈利和现金流能否在必要投入、偿债及资本约束后支持持续分配？ |
| Cyclical Value | 中周期利润、现金流、资产寿命和低谷偿债能力如何？ |
| Asset Value | 可回收资产扣除优先索偿、税费和等待成本后有多少价值？ |
| Growth at Reasonable Value | 增长是否创造价值，当前价格隐含的预期是否合理？ |
| Special Situation | 可核验事件、实现机制、失败情景与时间成本是什么？ |

路径允许重叠；行业、生命周期、资本结构与分配特征共同决定 ResearchProfile。高股息是正式研究路径，不是所有公司的统一门槛；高回报再投资企业不因派息低被机械淘汰。

## 最终用户工作流

L0 全市场身份与覆盖 -> L1 多通道基础筛选 -> L2 研究候选 -> L3 深度研究 -> L4 高关注 -> Human Decision。
Quality、Dividend / Cash Return、Cyclical、Asset Value、Growth Value 等通道汇入同一候选池，各保留入选理由和适用口径。详细迁移约束见 [architecture.md](architecture.md)。

用户每周看高关注和研究队列，每月复盘，财报季研究变化，分红季检查现金回报；重要事件触发提醒，无实质变化保持安静。高关注池允许为零。未来首页可优先展示 3--10 家，但不得以配额制造推荐。

Excel 目前是研究前端，未来 Web 复用同一研究引擎。用户应能在五分钟内知道覆盖范围、变化、值得研究的原因、最强反证、估值/股息判断边界和下一事件。

## 成功标准

- 同一流程适配不同经济画像，新增公司主要增加数据与配置，不复制整套流水线。
- 数字可以追溯到一手原件、口径、信息可用时点和计算版本；事实与未来假设可分辨。
- 同时解释价值增长、自由现金流、资本配置、分红可持续性及市场预期差。
- 测量覆盖质量、缺失原因、可复算率、错误放行、重要变化遗漏和用户复核成本，不以脚本数、测试数或每日信号数代表产品价值。
- Research Attractive、高股息、股息下降、价格不吸引和安全边际，均不得直接变成订单或仓位。

## 扩展路线与门槛

完整路线与毕业标准见 [LONG-TERM-GOAL.md](../LONG-TERM-GOAL.md)：已冻结的 C3 工程平台 -> M1 固定样本研究工作台 -> M2 全市场多通道发现 -> M3 决策理由/Entry Thesis/买卖一致性 -> M4 组合与股息管理 -> M5 事件监控 -> M6 初步真实辅助使用验收。每个 Milestone 单独启动，不一次性授权全部开发。
样本按经济特征和数据挑战预先选择，包含不支持、资料不足及负面案例，不按后验收益或易出估值挑选。不要求每家公司都有价格结论，必须能给出准确且可追溯的原因。

三公司股息材料可以逐步复用验证 Distribution Domain；历史分红记录存在不等于分红可持续性已通过。Decision / Portfolio 是正式长期产品范围，但尚未实现，当前 M1 不开发。Broker Execution 不属于这份路线，未来如需另行设计授权；研究准入不授权订单。

本轮仅审查和规划。用户启动 M1 后，在共享输入与PIT门通过的前提下允许预登记样本扩至20家，至少6家深研和原Excel研究展示；不再把“永不新增第四家”当长期约束。全市场、决策/仓位、Web、新金融模型、市场择时和券商交易均不属于 M1。

## 决策支持的长期产品边界

最终需要用理由卡回答为什么买、加、持有、减、退出；保存人工确认的 EntryThesisSnapshot、Decision Evidence Bundle 和 Decision Journal，持续比较原始论点与当前证据。所有状态都是人工复核，不是收益保证或自动成交。
组合层应考虑用户确认的目标/风险/现金/持仓、集中风险和可持续股息收入。低置信度、未知或重大反证不能被高安全边际抵消；没有个人约束不得猜测仓位，允许全现金。
