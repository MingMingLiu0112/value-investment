# 价值投资研究台账

## 日常查看顺序

打开原表后，从第一个工作表“00_首页Dashboard”开始。首页的绿色文字可点击跳转，按以下顺序查看：

1. 选公司：进入“00_公司总览”的已运行研究案例；其他公司单独放在“00_待完成公司”，可按工作进度、名单归属筛选。
2. 看生意：点击公司行的“看生意”，了解商业模式、竞争优势、研究假设及反证。个人研究笔记继续保留。
3. 看估值：查看对应公司的估值明细或案例中的“条件试算”。先核对报价日期、财报期间、假设和验证范围，再读价格与区间。
4. 看买卖条件：点击“看条件”进入“21_决策验证”，查看买入、加仓、减仓、退出的条件和未满足原因。研究结果不等于已批准交易。
5. 管持仓：进入“05_仓位管理”核对实际现金、持仓与组合约束。原模板金额不是已确认本金；研究虚拟账本也不是实际账户。
6. 记交易：人工成交后在“08_交易记录”记录数量、价格、理由，在月度复盘回看决策和持仓变化。

## 公司进度怎么理解

截至2026-09-12本次导航整理，743家公司分成1家已运行研究案例与742家待完成公司。两组互斥且覆盖当前候选和保留研究记录；固定研究案例即使不在当期初筛名单，也继续显示。公司是否有运行结果以可核验的运行记录判定，不靠“已跑通”之类的文字标签。

- 已运行研究案例：当前是贵州茅台，已有公司研究、条件估值、历史研究回放和幂等虚拟账本。进入案例页可依次阅读数据时点、条件值、当前状态和回放结果。
- 待完成公司：包含正在研究和尚未贯通的公司。美的集团列为研究进行中，中国神华保留为固定研究案例；每行展示已有内容和系统下一步，不表示这些公司完全没有数据。
- 完整策略验收：当前暂无通过。研究回放不能证明策略收益；茅台条件试算尚不构成已批准合理价或买卖点。

首页上半部直接展示茅台的报价日期、条件估值、当前行动和仓位状态，下半部提供六步导航。详细的22项策略规则保留在“00_使用说明”。

日常6页在前：首页、已运行研究案例、待完成公司、决策验证、仓位管理、交易记录。参考4页在后：公司研究、估值跟踪、指标证据、使用说明。其余18页保留但默认隐藏；可在工作表标签处取消隐藏后读取月度、财务、评分、审计等历史资料。

2026-09-12修复了WPS表内跳转：工作表链接现在使用内部位置，不再当作外部文件。参考页的大标题可点击返回首页；原始公告仍通过网页链接打开。使用说明中的D盘路径和Hash只是本机档案索引，不作为跨设备链接。

各页统一字体、表头和冻结列，低频明细列分组折叠。茅台条件三情景在估值页右侧单列；正式合理价与安全边际保持独立，未批准时不填。案例中的历史模拟现金与净值明确是回放期末记录，不是今日账户余额。

## 数据和明细怎么读

- 数据时点：查看案例页和“00_使用说明”的行情时点、服务导出时间与数据时效。此次导航发布没有刷新行情；导出刚完成也不代表行情刚更新。
- 提醒：买入研究、减仓研究、重点观察、常规跟踪与数据过期分开；无已知持仓不生成卖出指令。价格低于合理价、只是安全边际不足，不等于该卖出。
- 观察名单：保留初筛候选原始清单。初筛通过只是值得研究，不是买入批准；选公司时优先使用首页的进度分组。
- 财务指标：每行采用一个报告期，金额为亿元；黄色是尚未交叉验证的补充数据，绿色是自动交叉验证事实。空白不等于0。单元格批注提供来源和原单位。
- 金融专用指标：银行、券商和保险不用工业企业的负债率/自由现金流规则。每个披露数字都带报告期、验证状态、页码及原文证据。
- 估值跟踪：PE/PB不直接等于便宜；没有经验证假设就不输出合理价。EPS TTM只接受最近十二个月的对应字段，不用半年EPS替代。
- 公司研究、年报跟踪：新公司进入研究队列，但不自动编造护城河和投资结论。保留原有笔记。

## 评分如何理解

撤下最初10家公司的演示主观评分。现有非金融企业评分分为盈利35、现金25、稳健20、成长20分，只能作同类企业研究排序，不能当作预期收益。

缺少同报告期的自动验证指标时不出总分。中期ROE不与年度阈值混用，也不简单乘2或乘4年化。金融专用指标显示“取得/验证”覆盖率，不强行转换成通用100分。

质量评分独立读取年度数据，不让半年报覆盖年报；财务指标继续展示最新报告期。最新年度存在缺口时不会改用更早完整年度，每年5月起至少需要上一年度报告，旧年报不产生当前分数。年度事实同样保留在指标证据页。年度评分即使完整，也不能绕过最新财务、行情与估值的建仓门禁。

质量页右侧展示已取得的年度ROE、毛利率、净利率、现金利润比、资金与负债等评分输入；尚无可靠总分时隐藏空白分数列，保留取得/验证覆盖率。黄色输入不是已经通过评分门禁。

派生财务比率先统一人民币单位再计算。原始值、单位或来源发生变化时重新计算，保留输入来源、原单位与原值，不复用旧推导结果。

## 哪些页面不会机械填满

- 持仓管理、交易记录：不是研究候选清单，不虚构买入、仓位或成本。初始模板资产值可能是样例，并非券商真实资产。
- 月度跟踪：只追加已生成的月末快照，不伪造过去月份。
- 个人研究：原有研究保留，候选以外的旧公司留在末尾。
- 旧技术页默认隐藏且标为历史视图。当前指标证据集中到18页；旧审计和初始评分/估值/报告备注仍保留。

## 更新与安全

服务器按已有定时器采集；本地通过 `scripts/run_server_excel_sync.ps1` 下载并校验导出后生成表格。新生成器使用openpyxl，避免旧WASM导出的内存问题。

2026-09-07已核实并更新本机Windows任务`ValueInvestmentAgent-DailyUpdate`：工作日16:50启动服务器同步脚本。需要电脑开机、任务运行用户可读取专用SSH密钥且网络可达。服务器运行不依赖本机Docker。行情日常更新不再重复初始化数据库；有数据库结构变更时在部署阶段单独执行初始化。

下载先写独立暂存文件，SHA-256匹配后才替换本地导出；SSH连接超时15秒，配置15秒保活及三次无响应断开。网络失败不发布工作簿，也不把旧数据宣称为新行情。

WPS占用原文件时仍会生成runtime下带时间戳的新版文件，但不覆盖、不强制关闭原表。同步状态记录到runtime/excel-sync-status.json；关闭原表后再执行同步。生成期间原表有保存变动时也会停止发布，防止丢失新笔记。每次成功替换前保留技术备份。

“20_市场覆盖”记录当前响应的去重代码数、板块数量和互斥的排除原因。逐股票明细留在服务器按Hash归档的原始市场快照中；接口返回数量不等于已完成交易所全量证券清单对账。

当前已接入沪深北官方清单逐代码对账，2026-09-07快照5558只全部匹配。市场覆盖页展示匹配数、缺失/多余代码、板块冲突及各页原始响应Hash。对账通过只证明研究证券范围完整，不代表财务数据或买卖依据完整。每天清单更新失败时会记失败日志；不同日期的数据不会标成“已完成”。

低于2GiB可用磁盘时服务器暂停新增PDF下载，继续处理已归档证据。该保护不能替代扩容；不删除原始财报或其他项目资源。
