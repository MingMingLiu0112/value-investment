## 1. 确定采用的主模型

工业经营价值采用全部受控工业业务的100%经营现金流。财务公司采用股权估值，上市公司持有51%。工业少数股东索偿单独扣减；不能把全部工业价值乘95%，不能把财务公司49%少数权益再扣一次。

计算桥接为：

```text
归属上市公司普通股价值
 = 工业经营价值（100%，不含存款利息及金融业务）
 + 工业可分配外部金融资产净值
 + 工业对财务公司的净债权价值
 + 51% × 财务公司完整股权价值
 - 工业债务、租赁及其他尚未计入的优先索偿
 - 工业少数股东索偿公允价值
```

“工业可分配外部金融资产净值”必须扣除模型所需营运现金，并与现金流、受限资产及债务定义配对。工业少数股东索偿覆盖其经营资产与非经营资产份额，不能只扣经营利润却把全部子公司现金分给母公司。

## 2. 内部存款的处理修正

内部存款在合并报表抵销，不代表工业存款债权没有经济价值。拆除财务公司全部资产及负债并单独估算其股权后，应恢复相应工业债权；财务公司股权价值本身必须已扣除这项存款负债。

可用简化恒等式检查范围。设工业外部金融资产为C、工业对财务公司债权为D、财务公司资产为A、外部负债为L、其账面权益E=A-L-D、上市公司比例q：

```text
拆分账面归属 = C + D + qE
合并账面归属 = C + A - L - (1-q)E
两者必须相同。
```

若财务公司公允股权为F，两式都增加q(F-E)。这只是范围恒等式，既不证明账面价值等于公允价值，也不证明D可以立即全额提取。集团内工业少数股东及其他交叉债权另作穿透，不能遗漏。

因此须禁止的是“保留财务公司底层资产，同时再加内部存款及财务公司股权”，而非禁止所有拆分模型恢复内部债权。此前研究中的“不得重复加内部存款”应按此条件理解。
