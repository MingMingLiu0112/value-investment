## 现行规则与主要缺口

| 环节 | 当前实现 | 验证结论 |
| --- | --- | --- |
| 参考估值 | 同报告期 EPS_TTM×预设PE 与 BVPS×预设PB 的简单平均，仅10家预设公司 | 倍数和50/50权重尚未验证；两个模型不是独立一手证据 |
| 买入提示 | 数据门禁通过、安全边际至少30%、上游为建仓候选 | 阈值属于假设，不能推出盈利概率或最大亏损 |
| 财务质量 | 要求评分证据已验证且分数非空，并检查最新财务指标 | 提醒层没有独立最低分门槛；完整数据不等于优质企业 |
| 卖出提示 | 价格高于合理价，且已知持仓为正，才提示减仓研究 | 未定义减仓比例、基本面恶化退出及完整再入场策略 |
| 数据异常 | 阻断买卖研究提示 | 不代表已有持仓风险消失；后续应独立设计持仓风险提醒 |
| 行情时效 | 30小时及导出36小时检查 | 保守墙钟规则，不等于交易所日历；节假日可能产生过期提示 |

安全边际定义为 (估值-价格)/估值。估值100、价格70得到30%，回到100的未计成本涨幅为42.86%，不是30%；若估值本身应为60，70仍高估。该算例是代数检查，不是真实行情或收益预测。

## 冻结实验与执行边界

1. 沿用预选茅台600519、美的000333、神华601088，不按已看到的收益换股。三股只是跨行业案例，存在存续大公司选择偏差。
2. 目标2015-2025：开发2015-2019、验证2020-2022、测试2023-2025。不能因数据缺失悄悄缩短区间；当前历史并非真正未见数据。
3. 现行30%折价作为主假设，20%/40%作为敏感性实验，完整报告全部结果。估值方法、质量门槛和基本面退出属于独立实验，不混在主实验中调整。
4. 减仓提示尚不唯一对应成交策略。首次全额退出只能标为明确的实验假设，不能冒称精确复现现有减仓规则；分批比例、持仓上限、现金收益及分红再投资方式必须在绩效计算前写入运行配置。
5. 每个交易时点只使用此前已公开且口径合格的财报。不得把年度EPS铺成每日TTM、用今天估值回填过去、用后续重述值冒充当时原披露值。
6. 信号后下一可成交时点执行，处理T+1、停牌、涨跌停、数量约束、跳空和现金不足。分红、送转、除权与每股指标须同口径，不能重复计收益。
7. 同股买入持有为必需对照；宽基和行业对照必须明确价格/全收益口径。统一成本和资金，报告现金占用；不能用低仓位带来的低回撤冒充择时优势。

## 正式绩效运行前的剩余条件

- 冻结历史参考估值和完整下单数量/退出约定，完成引擎接入。目前Backtrader测试是合成执行检查，不是完整实股回测程序验收。
- 处理2015年早期沪市费用等缺口，不能默认零费用；无法核实的佣金/滑点只作显式场景压力测试。

## 结果应如何进入Excel

沿用21_决策验证，将三层状态分开：数据证据状态、策略历史验证状态、当前研究提示。正式结果至少包含运行ID、规则版本、样本与区间、累计/年化收益、最大回撤、基准差额、交易数、换手率、成本、现金占用和逐笔证据。

零交易、亏损、未跑完、缺数据均原样展示；不得只展示最好股票或最好阈值。三个案例通过也不能批准全市场筛选，仍须历史证券池及含退市/未入选公司的样本外验证。
