# 金融机构规则设计

## 适用边界

本规则仅适用于银行、保险和证券公司。它们不使用一般企业的自由现金流、净负债率或 EV/EBITDA 规则。未完成分类或未取得法定披露原件时，提醒只能是“重点观察/补全财报”，不得生成建仓或卖出建议。

## 证据优先级

1. 上市公司年报、半年度报告和季度报告原件，以及交易所法定披露页面。
2. 国家金融监督管理总局、人民银行、证监会等监管披露。
3. 公共聚合数据仅用于交叉校验，不作为正式结论依据。

每个进入计算的指标必须有报告期、单位、公告 URL、原文件 SHA-256、页码、复核人和复核时间。

## 银行

基础质量指标：归母净利润、EPS、归母普通股股东权益/每股净资产、ROE、净息差、不良贷款率、拨备覆盖率、核心一级资本充足率。

估值仅在最近年报或半年度报告的每股净资产、ROE 和资本充足率均已人工复核时允许计算。估值以 P/B-ROE 框架为主，P/E 只作辅助比较；经营现金流不得用作一般企业现金流质量结论。

阻断条件：监管资本数据缺失、关键指标来自不同报告期、出现重大审计保留意见、拨备/不良数据未复核、数据冲突未解决。

## 保险

基础质量指标：归母净利润、EPS、每股净资产、ROE、综合偿付能力充足率、核心偿付能力充足率、新业务价值及其增长、投资收益率。

估值以 P/B、ROE 和偿付能力安全边际为主。利润受投资收益、公允价值变动和会计准则影响显著，单期 P/E 不得单独驱动提醒。

阻断条件：偿付能力数据缺失、利润来源未拆分、会计口径变更未说明、关键指标未在同一报告期核验。

## 提醒分级

- 重点观察：官方报告已归档，关键字段已定位但尚未全部人工复核。
- 研究完成：同一报告期的基础质量指标均已复核，允许输出估值区间，但仍需人工确认。
- 建仓候选：研究完成，且估值安全边际、行业专用风险门禁、数据时效性同时通过。仅为研究建议，不执行交易。
- 阻断：任一关键披露、口径或审计条件不满足。
