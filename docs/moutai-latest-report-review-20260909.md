## 对经营假设的影响

2024增长不能直接外推：2025归母利润下降，2026上半年继续下降。下一估值情景需要同时覆盖低增长、利润率压力及恢复路径，不能把历史高增长作为默认基准。

2026中报第5、7至8页解释CFO大增主要为财务公司吸收成员存款增加、不可随时支取的同业存款减少；投资现金流增加主要为同业存单到期。现金释放与白酒客户销量的经济含义不同，不能将438.84%的CFO增幅当营业需求增长。

第8至9页原文观察：直销收入519.62亿元，i茅台不含税收入402.64亿元；合同负债31.78亿元，较2025年末下降60.31%。公司解释合同负债下降与市场化改革、销售模式和预收政策调整有关。这里是已阅读的原文观察，尚未加入九条自动重放行。

2024“i茅台下降”仍是历史事实，不再直接代表当前平台走势；新旧销售渠道定义及代售等变化要先核对，不能只把2026半年金额与2024全年金额机械比较。合同负债下降不能独立判定需求恶化，须结合政策与终端证据。公司对改革效果的描述是发行人判断，不等于独立验证。
